## 修复（v1.5.2）：官方解质量门槛

`StellarSolverNative.solveBitmapImpl` 对官方解统一验收（服务器 12 张标定）：

```
真解特征：logodds 26~907、nmatch≥15
噪声假解：logodds<10、nmatch=1
门槛：logodds < 25 或 nMatch < 2 → 拒绝（宁 FAILED 不报错误天区）
```

logodds 为 null（旧 .so）时不受影响。
