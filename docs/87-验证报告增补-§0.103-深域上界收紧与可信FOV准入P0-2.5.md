## 1. 问题

1. **深域上界 90° 过宽**：旧注释自称取 90° 是为"容纳真实宽场"，但**深域是窄场兜底
   路径**（目标 ≤20°）—— 真实宽场在浅域就该解出（宽场回归 12/12）；浅域整条阶梯
   都无解的宽场照片拿到 45°~90° 的"解"，基本是尺度坍缩伪影。
2. **缺可信视场入参**：`match()` 只收 `allowDeepRetry`，而 `StarSolver` 明明已经读了
   EXIF 视场（`readFovDeg`）却没传进去 → 宽场失败时仍可能白跑深域。
   真机实证：5057（74°~75°）在深域空转、打满 **60 秒硬上限**（PROGRESS §0.97）。
3. **深域解无来源标记**：调用方拿到解后分不清"浅域主路径解"与"深域兜底解"。

## 2. 改动

### 2.1 `astro/LocalStarMatcher.kt`

- `DEEP_PATH_MAX_FOV_DEG`：**90° → 45°**（docs/72 B2 与审计均建议 ~40°~45°）。
  取 45° 的理由：窄场/中场真值台覆盖 0.5°~20°，离此界很远；且**与准入判据共用
  同一个界**（一个口子、一处定义）。
- 新增准入判据（纯函数，便于单测）：
  `shouldSkipDeepRetry(fovHintDeg) = fovHintDeg != null && fovHintDeg > DEEP_PATH_MAX_FOV_DEG`；
  `matchLocked` 在深域重试前调用它 —— 命中则**跳过深域**并把原因写入
  `debugDeepRejectedReason`（新增留档字段，失败页/日志可读）。
  ⚠️ 判据**只允许用调用方传入的可信视场**：§0.98 曾按"浅域失败候选反推的视场"
  做同类闸门并当场回滚（那种候选被尺度坍缩伪解主导，与真实视场无关）——
  这条教训已写进代码注释。
- 新增 `enum CatalogDomain { SHALLOW, DEEP }` 与 `LocalMatchResult.catalogDomain`
  （默认 `SHALLOW`，既有构造点零改动）；深域解返回前 `copy(catalogDomain = DEEP)`。
- 深域解视场超上界时（原来静默 `return null`）**也写入拒绝原因**，便于诊断区分
  "深域没跑"与"跑了但被上界拒绝"。

### 2.2 `astro/StarSolver.kt`

- `LocalStarMatcher.match(..., fovHintDeg = fov)` —— 把手持的 **EXIF 视场**作为可信提示
  传入（`fov` 为 null 时行为与改动前完全一致）。
- 成功路径：日志与报告步骤追加来源标记 —— 深域解显示「· 深域兜底」。
- 失败路径：`why` 追加「深域：<跳过/拒绝原因>」，避免把"闸门生效"误读成"深域也解不出"。

## 3. 验证

1. **新增 2 项单测**（`LocalMatcherTest`，CI 常规执行）：
   - 准入判据边界：`null`/10°/45°（等于上界→**不**跳过）→ 允许；45.1°/74°（真机
     5057）/90° → 跳过；
   - 上界守卫：`DEEP_PATH_MAX_FOV_DEG ≤ 45`（防放宽回 90°）且 `> 20`（必须覆盖
     中场真值台的最大视场）。
2. **本机真跑 `LocalMatcherTest` 11/11 通过（38 秒）** —— 用缓存里的真实 Kotlin 编译器
   手动搭编译集（匹配器 + 星表 8 个分片 + 结果类型 + 测试；classpath 含 android.jar），
   其中包含 **9 项既有合成星空端到端测试** —— 证明上界收紧与新增参数**没有破坏浅域
   主路径**（"先加行为测试"原则的实践）。
3. `StarSolver.kt` + 匹配器联合编译：**0 语法错误**；本次改动的符号
   （`fovHintDeg` / `CatalogDomain` / `debugDeepRejectedReason` / `shouldSkipDeepRetry`）
   全部解析通过；其余报错均为缺依赖文件的级联。
4. **CI（GitHub Actions）**：`unit-test` **全绿** —— run `37891960530`，
   **23 类 / 200 项 / 0 失败 0 错误**（含本报告新增 2 项，`LocalMatcherTest`
   现为 11 项；与 §0.100/§0.101/§0.102 的既有测试同跑，无回归）。
5. ⚠️ **未验证（需 ≥4GB 内存机器）**：窄场/中场真值台
   （`NarrowFieldRegressionTest` / `SyntheticMidFieldTest` / `TieredCatalogTest`）
   依赖 `testdata/` 且深域索引构建内存需求高（项目自记"55.6 万三角形在 512MB 堆里
   跑不完"），本机 1.87GB 无法执行。**这是本批最重要的未验证项**，见 §4。
