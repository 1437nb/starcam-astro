# 验证报告增补 §0.18 — 相机弱光增强 v1.0.4（2026-08-28）

> 可直接粘贴进 `StarRecognizer\docs\验证报告.md`。缺点修复第二批（中等项）。

## 改动（CameraScreen.kt + AppIcons.kt）

针对「自动模式拍星空拍不到星」的核心场景短板，在 CameraX 能力范围内做软件层
最大提升（真实长曝光需 Camera2，列为后续）：

1. **夜景增强开关（🌙）**：工具条新增按钮，开启后
   `CameraControl.setExposureCompensationIndex(+2)`（按设备 EV 范围截断），
   预览与成片同步提亮，暗夜亮星更易成像。
2. **拍摄质量优先**：`ImageCapture` 模式从 `CAPTURE_MODE_MINIMIZE_LATENCY`
   改为 `CAPTURE_MODE_MAXIMIZE_QUALITY`——识别对星点清晰度敏感
   （§0.15：提星质量是手机端成功率的关键嫌疑），弱光场景以速度换画质值得。
3. **弱光提示条**：夜景开启时显示「请将手机固定（靠稳/三脚架）避免星点拖尾；
   更长曝光请使用系统相机专业模式」——诚实地说明软件边界。
4. **Night 图标**：AppIcons 新增月牙图标（Material nightlight path）。

## 验证

- 全量单测 44/44 全绿。
- 构建备注：768m 堆配置（§0.17 备忘）下本轮仍出现 2 次 OOM 后第 3 次成功——
  受限内存构建机的不稳定性依旧，`-Xmx768m` + drop caches + 重试循环是当前
  最可靠姿势。
