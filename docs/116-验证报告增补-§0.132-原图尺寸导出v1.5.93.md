# §0.132 原图尺寸导出（v1.5.93）

日期：2026-11-02。versionCode 113；updateDesc `original-resolution-export`。

## 使用流程与范围

识别成功后点击「保存当前标注」或「仅星座连线」，再选择：

- **预览尺寸**：沿用识别 / 查看用位图，速度快；
- **原图尺寸**：重新读取原始输入，在原始像素尺寸重新投影并绘制标注。照片带 EXIF 旋转时按正向输出，宽高可能互换；
- **RAW 内嵌预览尺寸**：读取当前 RAW 解码器能提取的 JPEG 预览完整尺寸，不宣称全尺寸传感器 RAW 解码。

导出尺寸以实际导入文件为准；若系统选择器事先缩小了照片，不能恢复已丢失的像素。所有模式输出 JPEG（沿用质量 95），保留选中的图层，不覆盖源文件。这里「原图」指像素尺寸，不代表原编码、位深、色彩配置、EXIF 或无损压缩。FITS 输出使用现有灰度拉伸并量化为 8 位 JPEG，不提供科学 FITS 数据导出。

单张、批量详情和历史结果共用该入口。部分旧批量历史只记「批量导出」，无法可靠判断原定标像素方向时，提示重新识别后启用原图导出；仍可保存预览尺寸。

## 实现与资源控制

1. `PhotoExportActions` 提供共享保存状态和可滚动尺寸选择框，显示真实输出尺寸、RAW / FITS 说明以及失败提示；中英文齐备。
2. `PhotoExporter` 在 IO 线程串行导出，重新解码原始输入而不是放大预览。常规正向图片直接在可变原图位图上绘制；旋转 / 镜像时创建正向输出并回收原栅格。
3. `PhotoExportGeometry` 处理八种 EXIF 方向、现有在线上传的旋转坐标基准以及原尺寸 WCS。缩放按像素中心计算；FITS 面积平均舍弃不足一组的边缘行列时，按实际采样覆盖区域还原，避免把裁切边缘强行拉伸到全尺寸。既有通用 WCS 缩放接口保持不变。
4. 星座连线、恒星、梅西耶和太阳系标记按原尺寸重新投影。日月 / 行星沿用结果页已确定的拍摄时刻与位置解算结果，不在导出时重新获取定位；文字、线宽和连线端点留白按输出倍率缩放。
5. 在线结果按上传时的方向还原坐标，再变换到输出照片方向。历史新增可选 `subid` 字段，保留在线定标身份；旧 JSON 可继续读取。
6. 解码前按尺寸 / 文件大小估算峰值：普通图片 4 字节每像素，旋转时按两张位图计；FITS 按 40 字节每像素加文件体积，RAW 另计容器读取和 JPEG 提取的空间；额外保留 16 MiB。预算取剩余 Java 堆的 75%、系统可用内存的 25% 和 384 MiB 三者的较小值。
7. 超预算、尺寸异常、源文件不可用或方向基准不明时明确报错，不自动缩小后继续称作原图。底层仍可能因系统瞬时内存变化分配失败，UI 捕获并提示；预算不是所有机型的无崩溃证明，也没有修复整个 FITS 解码器的流式内存问题。
8. 导出位图在成功、异常和取消路径释放；全局 Mutex 防止多张全尺寸导出同时分配。导航退出会取消协程，但不宣称能立即打断 Bitmap 解码、绘制或 JPEG 压缩等同步调用。
