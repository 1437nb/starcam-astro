# §0.141 全量缺陷审计与稳定性修复（v1.5.102）

本轮对仓库执行全链路缺陷审计并落地全部 28 项修复（含同步核验已修复项），重建原生 `libstellar_solver.so`，完成 62 类 / 400 项全量 JVM 回归以及本地官方签名 Release 构建与二进制审计。

## 核心修复汇总

1. **求解预算、取消与并发安全**
   - `SolveToken.kt` / `StarSolver.kt` / `ResultViewModel.kt`：分离用户取消与预算超限（`SolveBudgetExceeded`），保障预算超时仍输出失败诊断、落盘失败日志、保留预览图并计入统计；`raceSteps` 用 `try/finally` 保留超时前已提取星点。
   - `StellarSolverNative.kt` / `NativeSolveStep.kt`：将共享 `@Volatile` 失败诊断字段改为 `ThreadLocal` 消除批量并发竞态；收紧传感器/天顶先验预算占比，并对 `extStars` 重试扣减已消耗时间。
   - `astro_bridge.c`：在 `jni_is_cancelled` / `cancel_getter` 补全 `ExceptionCheck`/`ExceptionClear`，并在 `top_k_by_flux` 与 `extract_stars_impl` 补充 `malloc`/`calloc`/`strdup` 空指针及 `snprintf` 截断防护。
2. **在线 API 与存储 / 缓存生命周期**
   - `PlateSolveClient.kt` / `OnlineNovaStep.kt`：实现 HTTP 429/503 按 `Retry-After` 退避重试，补充 FITS 尺寸读取回退，本地化进度/报错文案，并将上传压缩纳入取消作用域。
   - `ResultScreen.kt` / `BatchViewModel.kt` / `StarCamApplication.kt`：修复屏幕旋转误触发 `onLeaveScreen()`、缓存项重试回写、在线识别 EXIF 方向一致、`ZoomableImageViewer` 回调释放，以及 `batch-display-*`/`import_*` 临时缓存清理与启动 6 小时过期清扫。
   - `ImageUtils.kt` / `HistoryStore.kt` / `SolveLogStore.kt` / `PhotoImportViewModel.kt`：补齐 MediaStore `IS_PENDING` 异常回滚、`HistoryStore` 与 `SolveLogStore` 并发保护及导入取消 join。
3. **天文数学、FITS 解码与匹配稳健性**
   - `FitsPixels.kt` / `FitsImage.kt`：将 `bzero + bscale * v` 提升至 `Double` 计算，修复 `BITPIX=32` 高偏置精度坍缩；`FitsMeta.fovDeg` 在缺少 `CDELT` 时回退解析 `CD1_1..CD2_2`。
   - `LocalStarMatcher.kt`：修复 8 邻域连通域洪泛栈越界（`sp < stackX.size`）、`boxBlur` 滑窗 `NaN` 传播与浮点漂移，以及极区网格近邻查询 `1/cos(dec)` 跨 RA 列展开。
   - `WcsTransform.kt` / `ExifPriors.kt` / `SkyRegionRecovery.kt` / `PhotoExporter.kt`：防御奇异 `CD` 矩阵、非法数值头卡片、负度分秒符号反转、GPS `(0,0)` 空岛、超界经纬度与除零。
4. **相机 / AR 与工程构建**
   - `CameraScreen.kt` / `ArSkyProjector.kt` / `LayeredRenderer.kt` / `AttitudeFusion.kt` / `QuatMath.kt`：修复 `onDispose` 必须先清 Pro AE 再 `unbindAll()`、实时闪光灯同步、切前摄重置 `proMode`、AR 校准对齐曝光帧时刻姿态、独立陀螺积分时间戳与线程安全、消除共享可变投影数组与窄画布 `coerceIn` 崩溃。
   - `AutoTest.kt` / `tools/release.py` / `docs/fdroid/com.starcam.astro.yml`：修正 `AutoTest` 传递真实路径以启用 EXIF 先验及流关闭，修正发版脚本预检顺序与 F-Droid 配方版本号同步。
