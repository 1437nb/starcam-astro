# 验证报告增补：§0.54 AR 找星导航与点击详情 v1.5.43

## 一、功能
在 AR 星图之上新增两个交互闭环：

1. **AR 找星导航**：顶部 🎯 按钮打开目标选择弹窗（44 个梅西耶 + 45 颗科普亮星，
   双语列表）→ 选中后 AR 画布实时引导：
   - 目标在视场内：绿色**脉冲光环** + 名称 + "✓ 已找到"；
   - 目标在视场外：**边缘方向箭头** + 名称 + "偏离 xx°"（用户朝箭头方向转）；
   - 目标在身后：画面中央 "↻ 目标名" 提示反向旋转；
   - 再次点 🎯（变 ✕🎯）清除目标。
2. **AR 点击详情**：AR 开启时轻点画面中的梅西耶/亮星标记 → 底部弹出科普卡片
   （复用结果页 `ObjectInfoCard`，类型/星等/距离/科普中英双语）；
   未命中才回落为原有点击对焦。与结果页/放大图三处入口交互统一。

## 二、技术要点
- `ArSkyProjector` 重构：抽出共享单帧参数 `Frame`（A 矩阵 + 针孔 f + 校准偏移），
  `project()` 与新增 `projectPoint(raDeg, decDeg, …)` 使用**同一帧参数**，
  保证目标环/箭头与星图严格对齐（含求解器校准平移）；
- 命中测试 `arHitTest` 基于 AR 显示矩形坐标 + 28dp/32dp 屏幕容差，
  梅西耶优先（与结果页一致）；
- 找星目标类型 `ArTarget`（Messier/Star 两种），选择弹窗 `ArTargetPickerDialog`
  按 梅西耶/亮星 分组，双语标签。

## 三、验证
- 新增 `ArSkyProjectorTest` 4 项：projectPoint 中心目标精确居中（±0.5px）、
  身后目标返回 null、针孔比例尺（10° 偏离 f·tan10 闭合）、校准平移后目标居中；
- `testDebugUnitTest` 全量回归通过；`assembleDebug` 成功：
  `StarCam-v1.5.43-AR找星导航与点击详情-debug.apk`（仅 debug）。
- 真机复测：① 🎯 选 M31 → 转动手机，箭头/偏离角随动，进入视场后脉冲光环
  "✓ 已找到"；② AR 中轻点 M31/天狼星 → 底部科普卡；③ 未命中仍可点击对焦。
