# 验证报告增补：§0.46 方向传感器辅助粗定标（Sensor-Assisted Coarse Pointing）

## 一、概述
针对星空拍照盲解面临的“全天球 41,253 平方度盲解搜索范围广、无先验时低端机耗时较长、极端噪点偶发跨半球伪匹配”问题，本项目实现了基于 Android 内置硬件传感器（旋转矢量/陀螺仪 + 加速度计 + 磁力计）与原生定位（GPS/网络）的**传感器辅助粗定标**闭环链路。

## 二、数学原理与坐标解算

### 1. 相机光轴姿态解算
- **设备体坐标系**：屏幕向右为 $+X$，向上为 $+Y$，垂直屏幕向外（朝向用户）为 $+Z$。
- **后置摄像头光轴物理方向**：垂直手机背面朝外，即设备坐标系下的矢量 $\vec{v}_{\text{cam}} = (0, 0, -1)^T$。
- **东北天（East-North-Up, ENU）世界坐标变换**：
  通过 `Sensor.TYPE_ROTATION_VECTOR` 获得旋转矩阵 $R$：
  $$\vec{v}_{\text{cam, world}} = R \cdot \begin{pmatrix} 0 \\ 0 \\ -1 \end{pmatrix} = \begin{pmatrix} -R[2] \\ -R[5] \\ -R[8] \end{pmatrix} = \begin{pmatrix} E \\ N \\ U \end{pmatrix}$$
- **高度角（$Alt$）与真方位角（$Az$）**：
  - 仰角：$Alt = \arcsin(U)$（度），$Alt > 0$ 表示朝向地平线以上星空；
  - 磁方位角：$Az_{\text{mag}} = \operatorname{atan2}(E, N)$（顺时针度数 $[0, 360)$）；
  - 地磁偏角修正：调用原生 `GeomagneticField.declination` 修正为真天球方位角 $Az = (Az_{\text{mag}} + \text{declination} + 360^\circ) \pmod{360^\circ}$。

### 2. 球面天文学转换（$(Alt, Az, \text{Lat}, \text{Lon}, t) \to (RA, Dec)$）
在 `SkyEphemeris.kt` 中实现 `altAzToRaDec`：
- 计算儒略日 $JD$、格林尼治恒星时 $GMST$ 与当地恒星时 $LST = GMST + \lambda$；
- 赤纬计算：
  $$\sin \delta = \sin \phi \sin a + \cos \phi \cos a \cos A, \quad \delta = \arcsin(\sin \delta)$$
- 时角计算：
  $$H = \operatorname{atan2}(-\cos a \sin A, \; \cos \phi \sin a - \sin \phi \cos a \cos A)$$
- 赤经：
  $$\alpha = (LST - H) \pmod{360^\circ}$$
- 严格单元测试通过：天顶极值（$\delta=\phi, \alpha=LST$）、北天极（$\delta=90^\circ$）、南中天过境与赤道地平点全量吻合。

## 三、核心模块与工程落地

1. **先验数据模型与缓存 (`PointingHint.kt`)**：
   - `PointingHint`：封装 $(RA, Dec, Alt, Az, \text{Lat}, \text{Lon}, t, \text{radius} = 25.0^\circ)$。
   - `PointingHintStore`：线程安全内存缓存，拍照瞬间记录照片与瞬时指向关联。
2. **三维姿态与定位追踪 (`DeviceOrientationTracker.kt` & `LocationHelper.kt`)**：
   - 监听旋转矢量传感器，以 $\alpha=0.25$ 指数平滑滤波抑制手持微颤；
   - 基于原生 `LocationManager`，无需任何 Google 服务依赖，开箱即用。
3. **相机取景实时 HUD 与 EXIF 注入 (`CameraScreen.kt`)**：
   - 顶部悬浮实时指向 HUD 徽标：
     - 朝向星空：`🧭 方位 185°(南) · 仰角 52° · 预估 RA 05h32m Dec +08°`（英文：`🧭 Az 185°(S) · Alt 52° · Hint RA ...`）；
     - 朝向地面：`🧭 手机未朝向星空（仰角 -15°）`；
   - 拍照瞬间注入 JPEG EXIF GPS 标签与内存缓存；
   - 实时预览认星 MVP（ImageAnalysis）接入指向先验加速。
4. **求解引擎先验升级与退避保障 (`StarSolver.kt` & `LocalStarMatcher.kt`)**：
   - **官方 Astrometry 引擎**：优先传入估计的中心 $(RA, Dec)$ 与 $25^\circ$ 搜索半径，搜索空间缩减 >90%；若无解自动平滑回退至天顶先验与全天分段盲解；
   - **自研星表匹配**：过滤跨半球伪对应，大幅减少 RANSAC 采样碰撞并杜绝跨天区假解。
5. **设置项与国际化 (`SettingsScreen.kt`, `I18n.kt`)**：
   - 设置页增加“传感器粗定标辅助”Switch 开关，支持即时启用/关闭；
   - 完整中英双语国际化支持。
