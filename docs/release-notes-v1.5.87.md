# StarCam v1.5.87 更新说明

**主题：全新品牌启动图标与首页双主题自适应徽章（§0.121）**

---

## 新增与视觉升级

- **全新「镜头取景 + 星座连线」品牌启动图标**：
  - **相机对焦取景框 + 光学镜头**：外围四角取景框与中央深空光学镜片、左上镀膜反光弧及四向天球方位刻度结合，直观展现「拍照识星（StarCam）」的产品定位；
  - **盲解特征三角形 + 星座折线 + 十字星芒主星**：镜片内融合致敬三角投票盲解算法的特征三角形（星云薄荷 `#9BD4C0`）、经典星座连线与双层金辉十字衍射主星（`#E3C567`）；
  - **全掩码安全区与 Android 13+ 主题图标支持**：核心前景严格收敛于 66dp 安全区内，完美适配圆角矩形、圆形、超椭圆等各厂商桌面掩码；新增 `ic_launcher_monochrome` 适配 Android 13+ Material You 桌面单色主题图标，并补齐 `ic_launcher_round`。
- **首页顶部双主题自适应品牌徽章**：
  - 在应用首页「星空识星」大标题上方新增 72dp 品牌图标展示（`StarCamBrandIcon`）；
  - 支持**深空蓝（默认）**与**夜视红（天文暗适应）**双主题自动变色：切换至夜视红模式时，图标自动转为黑底低亮红与暖琥珀配色，避免强光破坏观星暗适应视力。
