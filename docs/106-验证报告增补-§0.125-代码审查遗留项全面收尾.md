## 1. 背景与目标

`PROGRESS.md` 第一节第 11 项与 `docs/72-代码审查问题清单-20260922.md` 记录了代码审查遗留项：
1. **历史已修但状态未同步的四项（B2 / B3 / B13 / B14）**：
   - **B2**（深域视场 90° 上界过宽）：已在 `§0.103` 收紧为 `DEEP_PATH_MAX_FOV_DEG = 45.0` 并增加 `shouldSkipDeepRetry` 可信视场准入（`LocalMatcherTest` 与 `GateFovSweepTest` 覆盖）；
   - **B3**（AR 视场自动标定被弱解/深域解污染）：已在 `§0.112` 增加 `isHighConfidence` 门禁（要求浅域 `SHALLOW` 且 `inlierCount >= 18`，或官方引擎 `logodds >= 25.0`）；
   - **B13**（`BatchScreen` 用消息前缀判成败）：已在 `§0.101` 重构为强类型密封类 `BatchOutcome` 与三计数 `BatchTally`（`BatchOutcomeTest` 覆盖）；
   - **B14**（AR 预览 `FIT_CENTER` 矩形硬编码 `3/4`）：已在 `§0.115` / `§0.123` 提炼为纯函数 `CameraMath.computeFitCenterRect`（`CameraMathTest` 覆盖）。
2. **代码库中尚未清理的真实遗留项**：
   - `docs/72` **C 类全部条目**（注释漂移、死代码、调试埋点失真、i18n 双机制与死词条、AR FOV 手动滑块被后台重算覆盖、AR 太阳系点击未取最近、结果页星座 Chip 溢出裁剪、英文模式残留中文全角标点与无障碍标签、`SolarSystemEphemeris` 缓存缺同步、`HistoryStore.nearestConstellation` 全表三角函数遍历与 `NaN` 首星误命中）；
   - `docs/72` **D 类量化同构守卫单测**（`bucketKey` 与 `quantizeKeys` 零窗/查询窗同构断言）；
   - `docs/74` **§4 AR 逐帧零分配收尾项**（地平线求交闭包 `Ref` 分配、`Line2D`/`Messier2D`/`Solar2D`/`Label2D` 池化、星座标签质心零分配累加与英文切换支持、`OverlayScene` 包装壳池化）。

本节（`§0.125`）对上述全部遗留项进行逐一定点清理与单测固化。

## 2. 改动明细

### 2.1 `LocalStarMatcher.kt`（C 类清理 + D 类量化守卫）
1. **移除残留无调用私有死函数**：删除 `§0.115` `MatchContext` 无锁化后遗留的零调用私有函数 `snapshotDiagnostics()` 与 `matchLocked(...)` 及无用字段 `runtimeScoredCap`。
2. **`debugPhaseTimings` 统一七段格式与浅域留档**：
   - 此前 `matchInternal` 的 3 个提前退出分支（主投票强解、稀疏场多候选强解、弱星轮强解）仅输出 5 段（漏掉 `backupMulti` 与 `total`），且深域重试会直接覆盖浅域耗时；
   - 现统一通过 `formatPhaseTimings()` 在全部 4 个出口输出完整 7 段格式：`primary=...;multi=...;weak=...;backup=...;backupMulti=...;scored=...;total=...`；
   - 新增 `MatchContext.shallowPhaseTimings` 与 `LocalStarMatcher.debugShallowPhaseTimings`，切入深域重试前自动归档浅域耗时。
3. **`debugVoteTable` 修复 `looseFired` 恒为 0 的缺陷**：在宽松窗 `looseRaw` 合并循环中检测新增候选（`merged.put(k, t) == null`）并正确递增 `looseFired`。
4. **KDoc 口径对齐与量化方法可见性**：
   - 更新 `indexCache`（深域 55.6 万条、~9.3s）、`buildIndex`（说明浅域 `mag≤4.0` 与深域 `mag≤6.5` 双域职责）、`quantizeKeys`（单桶存储下 `window=2` 严格窗 / `window=14` 宽松窗）注释；
   - 将 `bucketKey` 与 `quantizeKeys` 声明为 `internal`，供单测直接守卫量化同构契约。

### 2.2 `Theme.kt`、`I18n.kt`、`SettingsScreen.kt`（消除 i18n 双机制与死词条）
1. **`AppThemeMode` 双语化（`Theme.kt`）**：为 `AppThemeMode` 增加 `labelEn` 与 `fun label(isEnglish: Boolean): String`。
2. **`I18n.Settings` 与 `I18n.Camera` 补齐（`I18n.kt`）**：
   - 新增 `I18n.Settings.parallelRacingTitle` / `parallelRacingDesc`；
   - 新增 `I18n.Camera.flashDesc` / `nightModeDesc` / `switchCameraDesc`；
   - `I18n.Result.formatSolveTime` 显式指定 `Locale.ROOT`。
3. **`SettingsScreen.kt` 全面接入 `I18n`**：消除页面内硬编码的 `if (isEn) ... else ...`，统一调用 `I18n.Settings.title`、`I18n.back`、`I18n.Settings.languageSection`、`languageDesc`、`appearanceSection`、`appearanceDesc`、`parallelRacingTitle`、`parallelRacingDesc` 及 `mode.label(isEn)`，激活全部原死词条。

### 2.3 `CameraMath.kt`、`StarChartOverlay.kt`、`LayeredRenderer.kt`、`ArSkyProjector.kt`、`CameraScreen.kt`（AR 逐帧零分配收尾 + C 类修复）
1. **消除地平线求交闭包 `Ref` 分配（`docs/74` §4.1）**：
   - 在 `CameraMath.kt` 新增纯函数 `computeHorizonSegmentInto(ru, uu, au, focalPx, rectW, rectH, out: FloatArray): Boolean`，内部采用纯基本类型局部变量完成四边求交，不声明任何局部嵌套函数，彻底消除每帧 5 个 `Ref$FloatRef`/`Ref$IntRef` 分配；
   - `CameraScreen.kt` 通过 `remember { FloatArray(4) }` 持有 `horizonSeg` 逐帧复用。
2. **`ProjectedSky` 全链路池化与 AR 星座名中英切换（`docs/74` §4.2, §4.3, §4.4, §4.5）**：
   - `StarChartOverlay.Line2D`、`Label2D`、`Messier2D`、`Solar2D` 字段改为 `var` 以支持容器级对象池更新；
   - `LayeredRenderer.OverlayScene` 的 `width`/`height` 改为 `var`，`ProjectedSky.toOverlayScene()` 直接复用容器内单例包装壳；
   - `ArSkyProjector` 预构建亮星星座下标表 `entryConIdx` 与 `conCodes`，在 `ProjectedSky` 内配置 `linePool`、`messierPool`、`labelPool`、`solarPool` 及质心累加数组 `conSumX`/`conSumY`/`conCount`，消除每帧 `HashMap` + `MutableList` + 包装对象的全部分配；
   - `ArSkyProjector.project(...)` 新增 `isEnglish: Boolean = false` 参数，`CameraScreen.kt` 传入 `isEnglish = isEn`，修复英文界面下 AR 星图星座名仍显示中文的问题。
3. **相机页 C 类交互与代码卫生修复（`CameraScreen.kt`）**：
   - **手动 FOV 滑块锁定**：新增 `fovUserOverridden` 状态；用户手动拖动 FOV 滑块后置为 `true`，后台每 5~8s 的实时预览自动标定不再覆盖用户手调值（切换前后置镜头时重置）；
   - **`arHitTest` 太阳系分支取最近**：修复原循环命中首个天体即 `return` 的不一致行为，改为遍历全部太阳系天体取距离最近者（与梅西耶、恒星及 `ResultScreen.hitTestObjectAt` 对齐）；
   - **清理短路死代码与硬编码无障碍文案**：将 `(exposureRangeState ?: 0L..0L)` 替换为不可变局部快照 `val expRange = exposureRangeState`；顶部工具条返回、闪光灯、夜景增强、切换镜头的 `contentDescription` 全部接入 `I18n`，所有 `.format(...)` 显式传入 `Locale.ROOT`。

### 2.4 `ResultScreen.kt`、`HistoryStore.kt`、`SolarSystemEphemeris.kt`、`StarCamApplication.kt`（C 类收尾）
1. **`ResultScreen.kt`**：
   - 「画面中的星座」`AssistChip` 行增加 `.horizontalScroll(rememberScrollState())`，防止广角照片包含多个星座时标签被右侧裁剪；
   - 方向角 `parity` 括号按 `isEn` 自适应半角/全角括号，浮点格式化统一传入 `Locale.ROOT`。
2. **`HistoryStore.nearestConstellation` 预索引与角距截断（`HistoryStore.kt`）**：
   - 预提取带星座标签的 ~919 颗亮星并预计算天球单位向量 `(ux, uy, uz)`，跳过 7,500 颗无星座标签的增补暗星；
   - 增加 `raDeg.isFinite() && decDeg.isFinite()` 守卫，修复传入 `NaN` 时因首轮 `best == null` 误返回星表第 0 颗星所属星座的缺陷；
   - 采用单位向量点积比较替代逐星 `sin/cos/acos`，并落实 `maxSepDeg = 15.0` 角距上界截断。
3. **`SolarSystemEphemeris.kt` & `StarCamApplication.kt`**：
   - `SolarSystemEphemeris.cachedTopocentric` 与 `clearCache` 增加 `@Synchronized`，消除多线程并发读写 `cacheJd`/`cacheResult` 的撕裂风险；
   - 删除 `StarCamApplication.kt` 中无操作的空重写 `override fun onConfigurationChanged`。
