## §0.36.4 上传链 EXIF 隐私审计（结论：通过，无需改代码）

- 审计对象：`ImageUtils.compressForUpload`（在线识别上传前处理）。
- 结论：`BitmapFactory.decodeFile` 解码即丢弃原图 EXIF → `Bitmap.compress(JPEG)`
  重新编码 → **上传内容为纯像素 JPEG，GPS 位置、时间、相机参数等 EXIF
  全部剥离**；方向信息经 `rotateByExif` 已物理旋入像素。
- 落地：设置页"隐私说明"明确告知"上传前已剥离 EXIF 位置信息；位置仅在
  本地用于天区先验"。

## §0.36.5 查看器/保存图渲染一致性修复（v1.5.14-dev，versionCode 34）

**回归事件**：用户反馈缩放查看器与屏幕预览不一致——星名变英文且变少、
星座线穿过星星没有留空、星座名全部消失。

**根因**：查看器与"保存到相册"共用 `renderAnnotatedBitmap`（早期保存函数），
其渲染逻辑与屏幕预览 `StarPhotoOverlay` 不一致：
- 连线直接 `drawLine`（未按星等留空）——预览用 `OverlayRenderer.shrink`；
- 星名用 `s.entry.name`（原始名，英文/空）——预览用
  `StarNames.displayName`（中文优先）且 mag>3.2 不显示；
- **完全没画星座名标签**（state.labels）——预览画了。

**修复**：`renderAnnotatedBitmap` 与屏幕预览三处渲染逻辑对齐（连线 shrink
留空、中文星名 + mag≤3.2 过滤、补画星座名标签）。保存到相册的图同步受益。

## §0.37 星座名样式调整 + 查看器原图/标注切换（v1.5.15-dev，versionCode 35）

用户反馈两项：

1. **星座名太大太浓**：屏幕预览与导出图（查看器/保存）的星座名标签同步调整——
   字号 14sp → 11sp，普通模式不透明度 0.55 → 0.36（0x8C → 0x5C），
   夜视红 0.4 → 0.33（0x66 → 0x55）。两处渲染逻辑保持完全一致。
2. **查看器增加原图/标注切换**：`ZoomableImageViewer` 接收（原图, 标注图）
   双位图，右上角新增「原图 / 标注」切换按钮，点击切换并重置缩放；
   成功页传"原图 + 星座标注合成图"，失败页传"原图 + 星点标注合成图"。

验证：全量单测 60 项全绿；UI 行为待真机确认（星座名观感、查看器切换）。
