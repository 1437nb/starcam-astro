## 2. 恒星专名现状盘点（探查结论）

- 星表 StarEntry.name 自带二十八宿中文名（壁宿二、奎宿一等），增补星为空；
- `StarNames`（3831 行，Stellarium 中国星官源）覆盖数千颗 HIP→中文名（天狼、织女一、参宿四、大角、勾陈一、河鼓二…），`displayName` 规则：中文名 → 星表中文名 → 拜耳命名；
- **离线识别结果页（ResultScreen）与保存/导出（OverlayRenderer）早已显示亮星专名**（mag≤3.2）；
- **缺口仅在相机实时预览**（renderLiveOverlay 只有星座线+星座名）→ 本次补齐：`renderLiveOverlay` 增加亮星星名（mag≤3.2，中文名优先）绘制。

## 3. 梅西耶深空天体标注（新功能）

### 3.1 数据

`astro/MessierCatalog.kt`：44 个广角星空照片常见目标，J2000 坐标（度）+ 中文名 + 类型：
- 星系（G）：M31/32/33/51/63/64/65/66/81/82/96/101/104/108/109 等
- 弥漫星云（N）：M8/16/17/20/42/43
- 行星状星云（PN）：M27/57/97
- 球状星团（GC）：M3/4/5/13/15/53/71/80/92
- 疏散星团（OC）：M6/7/11/35/36/37/38/41/44/45/67
- 类型颜色区分：星系暖黄 / 弥漫绿 / 行星状青 / 球状蓝 / 疏散粉

### 3.2 渲染（三处一致）

`StarChartOverlay.projectMessier(wcs, w, h)`：把梅西耶天体经 WCS 投影到屏幕，画面内返回可见项。

1. **识别结果页（ResultScreen）**：小圆圈（类型色）+ "M31 仙女座星系" 标签；
2. **保存/批量导出（OverlayRenderer）**：与结果页一致（ARGB 位图渲染）；
3. **相机实时预览（renderLiveOverlay）**：同款叠加，字号随帧宽自适应。

### 3.3 校验

AstroMathTest 新增 `messierIntegrity`：编号唯一、RA/Dec 范围合法、中文名非空、类型合法。

## 4. 验证集扩充评估（结论：需真机素材）

- 盘点 realphotos / photos12 / diag / sky50-img：**无新增真机照片**（12 张真机就是全部素材）；
- 评估 sky50 named 系列 20 张网络星空图（900-1200px）：自研引擎 **18/20 解不出、2 张错解**——引擎面向 76° 广角手机照片调优，这些窄场/模拟图不适用，且无独立真值，**不能自锚定纳入回归**；
- **结论**：回归台机制已就绪（truth map 加条目 + gray 文件即可扩展），真正的扩充需要用户手机补拍 8-10 张不同天区/亮度/构图（含月亮光晕、薄云、城市光污染）的照片入库。
