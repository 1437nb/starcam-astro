# 验证报告增补：§0.49b 拍照闪退修复 v1.5.36

## 一、问题（真机反馈：点击「拍照识星」按钮后直接闪退）

## 二、根因（静态定位，两处）

### 1. `IllegalFormatException` —— 崩溃的直接根因（v1.5.35 引入）
- `ui/camera/CameraScreen.kt` 底部 AR 视场校准滑块文案：
  `"视场校准 %.0f°".format(arFovDeg.roundToInt())` ——
  Java 格式化中 **`%.0f` 必须接受浮点参数**，传入 `Int` 直接抛
  `java.util.IllegalFormatException: f != java.lang.Integer`。
- 该 `Text` 位于相机页底部 Column 的组合阶段且 AR 默认开启 →
  **进入相机页即崩溃**，与"点击拍照识星按钮后直接闪退"完全吻合。
- **修复**：直接传 `arFovDeg`（Float）；已全量扫描工程其余 `%.f` 格式化调用，
  参数均为 Float/Double，无同类地雷。

### 2. `LocationManager.requestLocationUpdates` API 30+ 重载（v1.5.31 引入，潜在）
- 5 参重载 `(provider, minTimeMs, minDistanceM, listener, Looper)` 为 **API 30+**
  才有；minSdk 26 设备上会 `NoSuchMethodError`（当前被 `catch(Throwable)` 吞掉，
  不崩溃但 GPS 监听静默失效）。
- **修复**：改用 4 参重载（API 1+，回调在调用线程 = 主线程执行）。

## 三、修复后行为
- 相机页可正常进入；AR 星图（若传感器/定位可用）正常渲染，视场校准滑块显示
  "视场校准 62°"；`roundToInt` 仍被 EV 滑块使用，导入保留。

## 四、验证
- `testDebugUnitTest` 全量回归通过（含 AR 投影 6 项）；
- `assembleDebug` 构建成功：`StarCam-v1.5.36-拍照闪退修复-debug.apk`（仅 debug）。
- 真机复测：主页 → 拍照识星 → 不再闪退；AR 星图与 FOV 滑块正常。
