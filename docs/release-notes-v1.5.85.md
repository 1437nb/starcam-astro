# StarCam v1.5.85 更新说明

**主题：图层快捷开关与仅连线导出 + M45 与星名重叠避让修复**

---

## 新功能

1. **结果页图层快捷开关**：
   - 识别完成后，在照片下方提供横向滑动的快捷图层操作栏，支持一键切换：
     - **星星名字**（`Star names` / `星星名字`）：随时按需隐藏或显示恒星专名；
     - **星座连线**（`Constellation lines`）；
     - **星座名称**（`Constellation names`）；
     - **深空天体**（`Messier objects`）；
     - **月亮与行星**（`Moon & planets`，画面含太阳系天体时可见）。
   - 切换即刻生效，预览与双指全屏放大查看器即时同步。
2. **导出只有星座连线的纯净图片**：
   - 在相册保存区域提供双按钮操作：
     - **`📐 仅星座连线`**：一键导出背景星空 + 纯净星座连线图，无任何星名、文字或圈圈干扰；
     - **`💾 保存当前标注`**：根据当前所选的图层组合导出合成照片。

---

## 缺陷修复

1. **M45 昴星团与内部星名 Alcyone 重叠**：
   - M45 昴星团中心与最亮成员星昴宿六（Alcyone）在画面中处于同一坐标，旧版本直接重合绘制导致文字糊成一团。
   - 现当开启梅西耶深空图层时，自动抑制中心 28dp 内的成员星名字绘制（M42 猎户座大星云中心伐三等同样适用），消除文字重复冲突。
2. **星名超出图片画幅边缘被裁切**：
   - 修复画幅外边缘恒星判定缺陷，仅对坐标严格位于画面内的恒星排布名字。
   - 引入 **4 象限智能候选避让算法**（右上默认、右下适配顶部边缘星、左上适配右侧边缘星、左下）与全局安全边界收敛。
   - 顶部边缘星（如卷舌二、天船三）自动下移排布在星点下方，左侧边缘星（如参宿一/二/三）与右侧边缘星严格保持在画幅内，绝不越界被裁切。
