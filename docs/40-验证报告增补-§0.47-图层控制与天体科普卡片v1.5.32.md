# 验证报告增补：§0.47 星图图层控制与天体科普卡片 v1.5.32

## 一、概述
落实「方向一：星图交互与视觉精细化」两项核心体验升级：

1. **星图分层显示控制**：星座连线、恒星名称、星座名称、梅西耶深空天体 4 类标注独立开关，配合「按住看原图」即时对比。
2. **天体点击科普卡片**：点击画面中的梅西耶天体或亮星标记，底部滑出中英双语科普卡片（类型/视星等/距离/一句话天文背景）。

---

## 二、架构设计

### 1. 统一图层模型 `astro/LayeredRenderer.kt`（新建）
- `LayerFlags(lines, starNames, constellationNames, messier)`：4 类图层数据类，`LayerFlags.ALL` 为全开默认值。
- `LayeredRenderer.draw(canvas, scene, flags, isEnglish, density, night)`：单一绘制入口，按 flags 逐层绘制；`scene` 为 `OverlayScene(width, height, stars, lines, labels, messier)` 已投影数据（识别成功时一次性投影，处处复用）。
- `LayeredRenderer.renderBitmap(src, scene, flags, isEnglish)`：位图渲染（保存相册/查看器）。
- 收益：**消灭三处重复绘制代码**（原 `OverlayRenderer.render` / `renderAnnotatedBitmap` / Compose Canvas 内联绘制），预览、保存、放大查看三处渲染从此严格一致；夜视红主题配色内聚在渲染器中。

### 2. 天体科普数据 `astro/ObjectInfo.kt`（新建）
- `ObjectInfo.messier: Map<Int, MessierInfo>`：**完整覆盖梅西耶标注目录全部 45 个天体**，含视星等、距离（光年）与中英一句话科普。
- `ObjectInfo.stars: Map<Int, StarInfo>`：47 颗著名亮星（HIP 编号与 `StarNamesEn` 星名表严格对齐），中英科普。
- `ObjectInfo.typeLabel(type, isEnglish)`：5 类深空天体类型双语名称。

### 3. 结果页交互 `ui/result/ResultScreen.kt`
- **图层控制面板**：预览图右上 `≡` 按钮展开 4 开关（☑/☐ 复选样式）；开关状态由 `ResultScreen` 顶层持有，预览 Canvas、保存相册、放大查看器三处共享同一状态，保证所见即所得。
- **按住看原图**：`detectTapGestures.onPress + awaitRelease` 实现按住显示纯净原图、松开 120ms 淡入恢复标注（`Crossfade` 动画）；不与单击/双击冲突。
- **天体命中测试 `hitTestObject`**：把点击坐标经 letterbox（ContentScale 居中偏移 + fit-scale）换算到图像坐标系；梅西耶标记优先（28px 容差），其次最近亮星（36px 容差，限 mag ≤ 3.2 可见星）；命中弹出卡片，未命中则打开放大查看器（保留原行为）。
- **科普卡片 `ObjectInfoCard`**：底部半透明深蓝面板；梅西耶卡显示 `✦ + 类型色标 + label + 类型/星等/距离/描述`；亮星卡显示 `★ + 星名（双语专名）+ 星等/星座/距离/描述`；夜视红主题自动换深红底色。
- 保存到相册遵循图层开关：隐藏的图层不会被画进导出图。

### 4. 放大查看器 `ui/result/ZoomableImageViewer.kt`
- 新增可选参数 `renderAnnotated: ((LayerFlags) -> Bitmap)?` 与 `initialFlags`：右上角出现 `≡` 图层按钮，展开同款 4 开关；切换时经回调即时重渲染标注位图，**缩放与平移位置保持不变**。
- 原图/标注切换、双击缩放、捏合平移等既有能力不受影响。

### 5. 国际化 `ui/I18n.kt`
- 新增 `I18n.Layers`（panelTitle/lines/starNames/constellationNames/messier/holdOriginal/releaseToRestore）与 `I18n.InfoCard`（magLabel/distLabel/typeLabel/constellationLabel/tapHint）全部中英双语。

## 三、数据质量保障（单元测试 `ObjectInfoTest`，新增 6 项）

1. `starInfoHipsExistInCatalog`：科普表每个 HIP 必须存在于 8419 颗星表 —— **该测试上线首轮即捕获 1 处编号漂移（Mira HIP 10826 为长周期变星、星表 mag≤6.5 截止未收录），已修复**。
2. `starInfoHipsResolveToNames`：每颗星中英显示名均可解析，英文名绝不含汉字。
3. `messierInfoNumbersMatchCatalog`：科普表每个 M 编号必须存在于梅西耶目录，星等/距离/描述字段完备。
4. `catalogMessierFullyCovered`：梅西耶目录 45 个天体科普数据 100% 覆盖。
5. `typeLabelsBilingual` / `keyStarCardsAreCorrect`：类型标签双语抽查 + 关键星卡（天狼/北极星/参宿四/昴星团/仙女星系）内容防挂错抽查。

> 背景：亮星 HIP 编号曾出现成批张冠李戴（将 Aldebaran 的科普挂在 Algol 等编号上），本次以 `StarNamesEn` 实际映射逐条对齐修复，并固化单元测试防止回归。
