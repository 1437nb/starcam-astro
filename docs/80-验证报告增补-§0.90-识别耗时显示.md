# 80 · 验证报告增补 §0.90 —— 识别耗时显示

> 版本：v1.5.66（未发版；versionCode 86）
> 日期：2026-10-04
> 来源：开发者要求「加新功能在识图成功或者失败加入识别时间」

---

## 1. 做了什么

识别**成功页**与**失败页**各增加一行「识别耗时」。

- **成功页**：`InfoPanel` 里一行 `识别耗时 / Recognition Time`，与「识别引擎 / 中心坐标 /
  视场大小」同列（位置紧跟视场一行）。
- **失败页**：紧跟引导文案之后、重试按钮之前，加粗一行 `识别耗时：18.4 秒`。
- **口径**：与既有的 §0.40 打点计时**同一个数**（`ResultScreen` 里
  `t0 = …` → `System.currentTimeMillis() - t0` 包住 `StarSolver.solve` 本身），
  也就是写进 `StatsStore` 的那个毫秒值 —— 只计求解，不含照片解码。
- **不显示的情形**：演示模式（合成天区）与求解根本没开始的失败（读图失败等），
  此时状态里的 `elapsedMs ≤ 0`，两处都不渲染该行（**不是显示 0**）。

## 2. 文本格式

`I18n.Result.formatSolveTime(ms)` / `solveTimeLine(ms)`：

| 耗时 | 中文 | 英文 |
|---|---|---|
| 18 400 ms | `18.4 秒` | `18.4 s` |
| 60 000 ms | `1 分 0 秒` | `1 m 0 s` |
| 83 400 ms | `1 分 23 秒` | `1 m 23 s` |
| 0 / 负数 | `""`（不显示） | `""` |

先四舍五入到 0.1 秒**再**分档，因此 59 950 ms 显示 `1 分 0 秒` 而不是 `60.0 秒`。
失败页整行由 `solveTimeLine` 生成，中英标点各自正确（`识别耗时：` / `Recognition Time: `）。
