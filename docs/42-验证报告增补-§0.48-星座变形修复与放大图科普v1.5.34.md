# 验证报告增补：§0.48 星座变形修复与放大图科普卡片 v1.5.34

## 一、问题（v1.5.33 真机反馈）

### 1. 预览图星座严重变形（根因修复）
- **根因**：统一渲染器 `LayeredRenderer.draw` 用 `canvas.width/height` 推算坐标缩放比。
  Compose 预览的 `drawContext.canvas.nativeCanvas` 是**整块窗口画布**（如 1080×2400px），
  而非组合件绘制区（约 990×1320px）。窗口与位图（如 3000×4000）的宽高比不同 →
  x/y 缩放比不一致（0.36 vs 0.60）→ 星座连线/标注被严重拉扁。
- 导出位图与放大查看器路径 canvas 尺寸恰好等于场景尺寸（sx=sy=1），因此只有预览页变形。
- **修复**：`draw()` 新增 `drawWidth`/`drawHeight` 显式参数（默认仍取 canvas 尺寸，
  位图路径不受影响）；预览调用改传 `DrawScope.size`（组合件实际绘制区）。

### 2. 科普卡片接入放大查看器（新能力）
- `ZoomableImageViewer` 新增 `hitTest: (bitX, bitY, screenPxPerBitmapPx) -> SkyObjectRef?`
  回调；单指轻点（onTap）把点击点经 letterbox（ContentScale.Fit）换算为位图坐标后调用，
  **任意缩放/平移级别均可命中**（graphicsLayer 的视觉变换不改变 pointerInput 收到的本地坐标）。
- 命中后卡片以底部浮层显示在放大图内，底部手势提示自动上移避让；
  命中容差按"屏幕 28dp/32dp ÷ 当前像素比"动态换算，缩放越大容差越精准。
- 结果页预览与放大查看器共用同一 `hitTestObjectAt`（图像坐标系）实现。

## 二、规则重申（用户指令）

  上轮指令范围，本轮 v1.5.34 只出 debug）。
