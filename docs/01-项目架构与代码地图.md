## 1.1 识别链路总览（三层引擎）

```
拍照/选图
   │  EXIF 读取（ExifPriors.kt）
   │    ├─ 35mm 等效焦距 → FOV 区间（FovEstimate.kt）
   │    └─ GPS 经纬度 + 拍摄时间 → 天顶 RA/Dec（SkyEphemeris.kt，纯本地恒星时计算）
   ▼
StarSolver.solve(context, bitmap, priors)          ← 调度器
   │
   ├─[引擎① 官方 astrometry.net 0.97（NDK .so，主引擎）]
   │    ├─ 有天区先验 → solvePriors(ra, dec, radius, 21s)   ← solver_set_radec 通道
   │    ├─ 无先验 → 按 FOV 计划（fovRange 或 blindSegments 分段）+ 限时
   │    └─ 成败 → RA/Dec/orient/scale/parity + CD 矩阵 WCS
   │
   ├─[引擎② 自研 LocalStarMatcher（919 亮星三角形匹配，宽场补充 8°~180°）]
   │    └─ detectStars → 投票（多线程并行）→ RANSAC 相似拟合 → 全星表验证 → WCS
   │
   └─[引擎③ PlateSolveClient（在线 nova.astrometry.net 兜底，仅"仅在线"模式)]
        └─ login → upload → 轮询 → calibration 解析
   ▼
SolveResult + WcsTransform → ResultScreen 渲染
   ├─ 照片上叠加星座连线/星名（StarChartOverlay + Constellations + StarCatalogData）
   └─ 保存结果图到相册（ImageUtils）
```

引擎优先级（用户拍板，2026-08-27 调整）：**广角亮星表优先 → 官方 0.97 → 在线兜底**。
即 `StarSolver` 在 `ASTROMETRY_NATIVE` 分支里先跑天区先验轮（21s），失败回退 scale 计划；`LOCAL_STAR_MATCHER` 分支在宽场（>官方能力或官方失败后）优先尝试自研。

## 1.3 关键常量（StarSolver.kt）

```
NATIVE_FOV_MAX_DEG = 180.0        // 官方引擎视场上限（index-4119 quad 直径可达 60°+）
LOCAL_FOV_MAX_DEG  = 180.0
NATIVE_TIME_LIMIT_KNOWN_FOV = 30.0   // 有 FOV 先验的官方求解限时（秒）
先验轮限时 = NATIVE_TIME_LIMIT_KNOWN_FOV * 0.7 ≈ 21s
blindSegments() = [(3.0, 40.0, 12.0), (40.0, 120.0, 16.0)]  // (fovLo, fovHi, 索引号) 盲解分段
skyPriorRadiusDeg(fov) = fov/2 + 45°，clamp 60°~85°；无先验默认 67.5°
```

## 1.4 JNI 桥（app/src/main/cpp/astro_bridge.c）

导出符号：`Java_com_starcam_astro_astro_StellarSolverNative_{solve, solvePriors, extractStars, extractStarsE3}`。

- 内部用 **simplexy**（0.97 自带，替代 SEP）提星 + **solver_t C API** 求解（见 03）。
- 超时：20ms 轮询 `solver->quit_now = TRUE`（bionic 无 `pthread_timedjoin_np`）。
- 索引加载：`index_load()`（APK 捆绑 index-4112~4119）。
- 输出 JSON：`ok, ra, dec, orient, pixscale, parity, nmatch, indexid, logodds, cd00, cd01, cd10, cd11, fieldw_arcmin, fieldh_arcmin`。
- `simplexy_enable_parallel()`：按核数调 `simplexy_set_nthreads`（提星路径并行，见 03 §3.6）。

## 1.5 WCS 坐标系约定（易错！）

- 官方求解器输出的 CD 矩阵是 **FITS 约定（y 向上）**；屏幕坐标 y 向下。
- Kotlin `WcsTransform(crpix1, crpix2, crval1, crval2, cd11, cd12, cd21, cd22)` 中 **`cd21` 必须翻号**（fits y-up → screen y-down）。
- 自研 LocalStarMatcher 与官方 CD 输出已对齐（§0.6 有逐位一致性验证）。
