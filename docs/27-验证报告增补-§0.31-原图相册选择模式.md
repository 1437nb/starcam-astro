# 验证报告增补 §0.31 — 原图相册选择模式 v1.5.6-dev（2026-08-31）

> 可直接粘贴进 `StarRecognizer\docs\验证报告.md`。

## 背景

用户反馈（HyperOS）：通过系统相册选择照片时进入厂商"安全访问"界面，所选照片的
**位置信息与拍摄参数（EXIF）被隐藏**。对本 App 影响实质：`StarSolver.readFovDeg`
（EXIF 焦距 → 视场）与 `ExifPriorsReader`（GPS+时间 → 天区先验）双双失效，
识别退化为盲解（变焦/窄场照片更容易失败）。

机理：厂商在**系统选择器层**对第三方应用脱敏 EXIF（有意的隐私设计，无官方 API
可从该选择器拿回原图）。脱敏不在文件本身——DCIM 里的原文件 EXIF 完整。

## 方案（正当授权，非绕过）

AOSP 标准媒体权限 + 内置相册：

1. `GalleryScreen`（新增）：App 内嵌相册页。首次进入请求 `READ_MEDIA_IMAGES`
   （API 33+）/ `READ_EXTERNAL_STORAGE`（≤32）——用户一次性显式授权；
2. 经 MediaStore 按 `DATE_ADDED DESC` 列出照片，读取 **DATA 列原文件路径**，
   直接解码/读 EXIF（原图完整，含位置与焦距）；
3. 支持单张识别与多选批量（≤9，与既有批量管线一致）；
4. 用户拒绝权限时给出说明与重试；主页保留系统选择器为"兼容模式"入口。

各厂商（HyperOS/鸿蒙/ColorOS 等）行为一致：都是 AOSP 标准合同，无厂商私有 API。
