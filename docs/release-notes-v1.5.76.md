# StarCam v1.5.76 更新说明

**主题：FITS 与相机 RAW 支持 + 二期审计三条修复**

这一版有两块：**能读专业素材了**（望远镜 FITS / 相机 RAW），以及**把二期审计在上一版
代码里查出的三条缺陷修掉**（其中一条会让六成拍摄时间的 EXIF 时间解析失效）。

## 新功能：FITS 与相机 RAW

- **FITS（`.fit` / `.fits` / `.fts`）**：望远镜与冷冻相机的标准格式，直接导入即可识别。
  - 自研解码器（离线、无第三方库）：支持 8/16/32/±32/±64 位深、BSCALE/BZERO 定标、
    多 HDU（图像在主头之后也认）、以及各类头部写法容错；
  - 解码口径与项目回归台把 FITS 转素材的参考实现**逐点一致**（验证机 31 张真实 FITS
    实测最大差 ≤ 0.00005），保证"手机上认出的"与"回归台上验过的"是同一张图；
  - FITS 头里的信息直接当识别先验：**WCS 视场**（用于判断该不该走窄场深域路径）、
    `DATE-OBS` 拍摄时刻（日月行星标注）、`SITELAT/SITELONG` 观测站坐标；
    望远镜素材**不**用手机当前位置兜底（拍摄者在观测站，用手机定位标注只会错得更离谱）。
- **相机 RAW（CR2 / NEF / ARW / DNG / ORF / RW2 / RAF / PEF / SRW…）**：取相机写进
  文件里的**内嵌预览图**来识别 —— 不需要任何第三方 RAW 库，全离线、包体不增大。
- **入口**：首页新增「FITS / 相机 RAW 文件」（系统文件选择器）；也可以把它们放进
  批量识别一起处理。缩略图、结果页、叠加渲染、在线兜底上传全部打通。

## 修复（二期审计，2026-10-14）

1. **EXIF GPS 时间在"时/分/秒 < 10"时失效**（v1.5.75 引入的回归）：替换日期格式化器时
   漏掉了"两位宽"的要求，导致一天里 **59.5% 的拍摄时刻解析失败**（静默退回本地时间 →
   天顶先验与日月行星位置降级/偏错）。已改为日期与时分秒分开组装，并补了单数位回归测试。
2. **内存紧张时可能崩溃**：系统在前台低内存回调里让 App 释放星表索引缓存，而回收闸门
   只统计了"超时泄漏的线程"、**没算正在求解中的线程** —— 正在识别时会读到已释放的内存
   （use-after-free）。已改为按"持有索引引用的活跃求解数"记账，并补了 C 层主机测试
   （修复前实测可稳定复现崩溃条件）。
3. **诊断信息串台/过期**：批量识别两个任务并发时，日志里的投票轮/打分轮统计可能读到
   另一个任务或上一张照片的数字（涉及"跑了多少星、对齐多少颗"的排查结论）。已改为
   每次求解在锁内快照、随结果返回；native 失败诊断字段也改为每次入口清零。

配套工程改动：C 层状态机测试接入 CI（<1 秒，无需 NDK）；全量单测 255 项 / 38 类。
