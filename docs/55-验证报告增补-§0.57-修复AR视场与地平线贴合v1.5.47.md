# 验证报告增补：§0.57 修复 AR 视场缩放与地平线贴合 v1.5.47

## 一、背景与问题诊断
v1.5.46 零分配找星导航重做后，用户确认“抖动消失了”，但反馈 AR 实时星图存在新问题：“地平线不固定不像stellarium那样，且星空显示错误；视场/缩放不对, 地平线不贴合”。
经全链路数学与几何排查，定位 5 项根本原因：
1. **地磁偏角未作用于传感器三轴基**：Android `Sensor.TYPE_ROTATION_VECTOR` 默认对齐磁北，而 `ArSkyProjector` 赤道转换对齐真北；未施加磁偏角旋转导致星图横向系统性偏斜（数度至十数度），与地平脱节且与 HUD 真方位不一致。
2. **2D 屏幕平移校准机制缺陷**：`arCorrectionVec` 将单次求解中心用 2D 偏移拽向屏幕中心 `(cx, cy)`；转动手机时星空被严重扭曲并在 85° 处突变暴跳，且地平线完全未受平移，导致星图与地平线严重撕裂。
3. **地平线倾斜除零与无方位标尺**：`horizonY(u)` 在大滚转角或横屏时 $uu \to 0$ 导致除以零，地平线消失闪烁；且仅有居中固定文字，无 Stellarium 式地平方位标尺。
4. **FOV 自动标定误选超广角与相机流比例未锁**：多摄机型 `firstOrNull()` 易误选超广角焦距（如 1.85mm，算得 >90° FOV），导致星图缩放极小；CameraX 预览流未显式锁定 4:3。
5. **传感器预测时钟基准差异**：`predicted()` 混用 `System.nanoTime()` 与 `SensorEvent.timestamp`（基准为 `elapsedRealtimeNanos`）。

## 二、改动与修复要点
1. **真北世界坐标系统一（`DeviceOrientationTracker.kt` + `CameraMath.kt`）**：
   - `CameraMath.rotateBasisAroundUp`：实现绕世界铅垂轴（Up）顺时针旋转，保持各向量的世界铅垂 Z 分量（`ru, uu, au`）与滚转角（`rollDeg`）绝对不变。
   - `buildPointing` 在获取 `GeomagneticField.declination` 后将三轴基顺时针旋转 `declinationDeg`，使三轴基与投影引擎严格落在真北东北天体系中。
   - `predictedPointing` 改用 `SystemClock.elapsedRealtimeNanos()` 对齐传感器时钟轴。
2. **三维航向校准取代 2D 平移（`CameraScreen.kt`）**：
   - 废除 2D 屏幕平移拉扯。求解器在 AR 模式命中后，将中心赤道坐标转为真北地平方位 $az_{solve}$，计算当前航向残差 $\Delta az = az_{solve} - az_{sensor}$ 并更新实际 FOV。
   - 渲染时通过 `rotateBasisAroundUp` 整体旋转三轴基，全天球 360° 旋转时校准持续平滑生效，永不撕裂、永无跳跃。
3. **鲁棒地平线 4 边求交 + 8 方位罗盘标尺（对齐 Stellarium）**：
   - 直线方程 $A\cdot x + B\cdot y + C = 0$ 采用矩形 4 边求交，彻底消除 $uu \to 0$ 除零与地平线消失问题，任意倾角稳定绘制。
   - 在地平线上沿海拔 0° 投影 8 个主要地平方位（北/N、东北/NE、东/E、东南/SE、南/S、西南/SW、西/W、西北/NW），转动手机时标尺平滑滑动，宛如真实地平仪，完全对齐 Stellarium 体验。
   - `I18n.Ar.cardinalLabel` 支持中英双语方位标签。
4. **主摄 FOV 优选与 CameraX 4:3 锁定**：
   - `CameraMath.selectMainCameraFocal`：遍历多焦距，选出换算 FOV 最接近标准主摄（~62°）的焦距，避免误选超广角或长焦。
   - `Preview.Builder()` 与 `ImageCapture.Builder()` 显式配置 `.setTargetAspectRatio(AspectRatio.RATIO_4_3)`，保证预览流与 AR 绘制矩形 1:1 绝对贴合。
5. **零分配维持**：
   - 地平线与罗盘标尺所有 Paint（horizonPaint, cardinalDotPaint, cardinalMajorTextPaint, cardinalMinorTextPaint）及 scratch 数组在 `remember` 中一次性分配，维持 60fps 跟手流畅度。
