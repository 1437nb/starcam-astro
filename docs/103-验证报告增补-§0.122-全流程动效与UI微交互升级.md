## 一、升级背景与目标

StarCam 拥有扎实的天文数学模型、离线盲解引擎与 AR 姿态解算能力。但在界面体验上，各界面切换曾使用统一的水平平移，相机的快门与对焦框反馈较为平淡，解算等待状态仅有静态圆环与普通文字，天体详情与图层控制弹窗缺乏符合现代 Material 3 规范的微动效。

本期（`§0.122`）全面优化全流程 UI 视觉与微交互动效：
1. **多场景差异化页面转场**：区分相机全屏与标准界面层级，杜绝相机取景器黑屏撕裂；
2. **首页天文品牌呼吸与浑天仪星环动效**：赋予首页核心标识天体运转的生命力与仪式感；
3. **今日天象折叠交互弹性动画**：弹簧物理展开/收起，箭头平滑 180° 翻转与动态阴影；
4. **相机快门手感与对焦反馈**：快门按钮触感弹簧缩放、拍摄中光波扩散环与对焦框弹性收敛；
5. **解算高科技雷达扫描与天体弹出动效**：盲解等待时呈现垂直渐变雷达光带扫描及候选星点呼吸晕光，天体卡片与图层面板平滑弹出。
6. **零每帧垃圾回收（Zero Allocation in Draw Loops）**：所有动效基于 Compose 标量状态驱动与原生 Canvas 绘制，不增加任何每帧对象分配。

## 二、详细改动清单

### 1. 页面转场动效升级 (`StarCamApp.kt`)
- **相机界面专属转场**：进入相机界面使用 `fadeIn(tween(350, easing = LinearOutSlowInEasing)) + scaleIn(initialScale = 0.94f)`，退出使用 `fadeOut(tween(250)) + scaleOut(targetScale = 0.96f)`。避免传统水平滑窗撕裂相机 SurfaceView/PreviewView。
- **其他屏幕层级转场**：进入采用 `slideInHorizontally(animationSpec = tween(320, easing = FastOutSlowInEasing))` 伴随淡入，退出采用水平反向滑出与淡出。

### 2. 首页品牌与按钮微交互 (`HomeScreen.kt`)
- **星体呼吸律动**：`rememberInfiniteTransition` 驱动 `brandBreathScale`（0.985f ~ 1.015f，周期 3200ms），模拟宇宙天体脉动。
- **浑天仪坐标刻度星环**：在外围 `Canvas` 绘制带有天球坐标刻度（0°/90°/180°/270°）的精密星环，随时间慢速公转（`astrolabeAngle` 0° ~ 360°，周期 36s）。
- **核心操作按钮触控动效**：相机主按钮与相册辅助按钮配置动态按压阴影（`animateDpAsState` 0.dp -> 6.dp）与高质感圆角。

### 3. 今日天象卡片弹性交互 (`TonightSkyCard.kt`)
- **弹性展开折叠**：`AnimatedVisibility` 结合 `expandVertically(spring(stiffness = Spring.StiffnessMediumLow, dampingRatio = Spring.DampingRatioLowBouncy)) + fadeIn()`，展开体验极具弹性质感。
- **展开箭头旋转**：`chevronRotation` 采用 `animateFloatAsState` 实现 0° 到 180° 的丝滑翻转。
- **动态高度立体阴影**：展开时卡片阴影从 `1.dp` 动态过渡至 `6.dp`。

### 4. 专业相机快门与对焦体验 (`CameraScreen.kt`)
- **防重复触发保护**：引入 `isCapturing` 状态机，防止快门连击与状态失锁。
- **快门弹簧触感**：按下快门时使用 `animateFloatAsState(targetValue = if (isShutterPressed) 0.88f else 1.0f, animationSpec = spring(...))`，提供真实的物理快门顿挫感。
- **拍摄中光环扩散波**：拍照曝光期间在快门外圈激活动态雷达扩散环（`capturingPulseAlpha` 与 `capturingPulseScale` 1.0f -> 1.35f）。
- **手动对焦收敛框**：点击取景画面对焦时，对焦框由外向内弹性收缩（`focusFrameScale` 1.35f -> 1.0f），指引视觉落点。

### 5. 解算等待雷达扫描与天体弹出 (`ResultScreen.kt`)
- **天文雷达激光扫描**：在盲解预览图上生成自上而下的纵向渐变光带（`sweepProgress` 0f -> 1f，2600ms 匀速线性循环）与发光激光指示线。
- **星点呼吸光晕**：已提取的候选星点显示双层光晕（外层金黄柔光晕 `radius * 1.6f` + 核心清晰描边），配合 `starGlowAlpha`（0.40f ~ 0.95f，1100ms 正弦呼吸）实时律动。
- **天体卡片与图层面板平滑弹出**：
  - 点击照片中梅西耶天体/亮星时，天体卡片使用 `slideInVertically(initialOffsetY = { it / 2 }) + fadeIn()` 自底部弹性滑出。
  - 图层控制面板使用 `fadeIn() + expandVertically()` 展开。
