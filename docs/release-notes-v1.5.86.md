# StarCam v1.5.86 更新说明

**主题：修复预览图与大图放大查看器图层状态不同步问题**

---

## 缺陷修复

- **预览图与大图查看器图层状态一致性**：
  - 修复前：在结果页预览图中通过 FilterChip 或图层菜单切换图层（如只勾选星座连线和星座名称），点击图片进入全屏双指放大查看器时，大图依然显示了所有图层（包含星名、深空天体等）。
  - 根因：`StarPhotoOverlay` 内部的点击手势检测（`pointerInput`）闭包未建立对动态图层状态的追踪，点击放大时调用的合成函数捕获了初次加载时的旧状态快照；同时 `ZoomableImageViewer` 内部缓存状态缺乏双向同步回调。
  - 修复：
    1. 引入 `rememberUpdatedState` 与动态 key 重构手势系统，点击放大即时合成与当前预览完全相同的自定义标注底图；
    2. 全屏大图查看器支持 `onFlagsChange` 双向同步，在全屏大图里调整图层开关时，返回结果页即时同步状态；
    3. 天体点击科普检测（`hitTestObjectAt`）增加图层状态感知：当用户隐藏星星名字或行星时，点击该区域不再弹出对应卡片并允许顺畅放大；
    4. 全屏大图图层控制菜单补齐「月亮与行星」开关项。
