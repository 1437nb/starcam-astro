## §0.32.1 导航栈重构（返回语义修复）

- 背景：旧实现为单页状态，所有 onBack 一律 `navigate(Home)` + 根级 BackHandler
  回 Home——"历史 → 结果"场景下返回会跳过历史列表直接回主页。
- 改动：`AppViewModel` 改为栈式导航（`mutableStateListOf` 为栈，根为 Home）：
  `navigate` 压栈、`goBack` 弹栈、`canGoBack = size > 1`；`StarCamApp` 的统一
  `BackHandler` 与各页返回按钮全部改走 `goBack()`（手势/三键/按钮同一语义）。
  重拍（Result → Camera）为压栈，返回序列逐级回退。
- 测试：新增 `AppViewModelTest` 5 项（根页边界、深栈逐级回退、Gallery/Batch
  回退），全绿。

## §0.32.2 本地解官方交叉复核（§0.29 遗留项落地）

- 原则：**宁缺毋假**的最后一道闸，但以不误杀为底线。
- 决策（`StarSolver.crossCheckAccept`，纯函数，JVM 可测）：
  - 内点 ≥ 18：自研解高置信 → 免复核直接呈现（省真机时间）；
  - 内点不足：用官方引擎（自带 logodds≥25/nMatch≥2 门槛）在自研视场
    ±35% 内复核一次（10s 上限）：
    - 官方无解 → **不拦截**（宁放过不误杀——引擎不可用/限时未出均走此路）；
    - 官方有解且 Δ天区<3°、视场比 0.5~2 → 接受；
    - 官方有解但不一致 → **拒绝**（拦截"宽场误判窄场特写"型假解）。
- 目标场景：5087/5092（低内点边界解）此前呈现不稳定，复核通过则呈现可信度
  上升，不通过则自动流转到官方引擎正解路径。
- 测试：新增 `CrossCheckTest` 7 项决策矩阵（高内点免检/无解容忍/一致接受/
  天区偏移拒绝/尺度坍缩拒绝/RA 跨 0° 包装/临界偏移拒绝），全绿。
- 注意：复核本身调用 .so，真机行为待回归清单 §28 验证；JVM 已测纯决策层。

## §0.32.3 双阈值投票通道（v1.5.8-dev，versionCode 28）

**回归事件**：realphotos 素材取回后首次全量 47/47，apod4（北斗 34° 网络小图）
从基线 SOLVED 变 UNSOLVED——§0.30 的纯相对阈值（20 亮星 ×35%）对小图是错的。

**机理**（诊断链：调试投票表 → 阈值双分支对照 → DBG 日志 → 指纹比对）：
- apod4（719×507 小图，≥900 亮星 16 颗）：需要"亮星精锐"投票（work≤16），
  work=45 时暗星/噪声三角形产生海量假验证票，把真票 margin 挤没
  （顶票 21v vs 20v 全被 1.2× 胜出线拦下）；
- 4984/4998（2200px 大场）：曝光整体偏暗，900 门槛把真星表星挡在投票外
  （4998 work=14 失败），必须相对阈值（work≥28）；
- 两者亮度分布统计几乎相同（816/793、16/15 颗 ≥900）——**不存在单一亮度
  判据**。

**方案**：`voteThresholds` 返回 (主, 备) 两档（900 固定档与相对档），
`tryMatch` 先主档：**主档强解（内点 ≥18）直接返回；弱解或空继续备档；
备档只有拿到强解才反超主档**（弱解间以主档为准——备档弱解顶掉主档真解、
再被跨度门槛拦截成 UNSOLVED 的回归已实测并固化为此规则）。
