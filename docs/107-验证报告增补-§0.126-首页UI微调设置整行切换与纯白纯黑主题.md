## 一、需求背景与改动细节

### 1. 首页按钮与今日天象板块 Emoji 清理
- **问题**：原主页按钮文字与次级列表行内混杂了 Emoji（如 `📷 拍照认星`、`📁 FITS`、`✨ 离线演示`、`🕘 识别历史`、`⚙️ 设置`），在左侧已有标准 Material 图标的情况下视觉过于繁杂；今日天象板块展开后的各行星行首全部硬编码了相同的 `🪐`（土星）Emoji，既不准确又影响观感。
- **改动**：
  1. [`I18n.kt`](file:///c:/starcam/code/app/src/main/java/com/starcam/astro/ui/I18n.kt)：清理 `takePhoto`、`chooseFitsRaw`、`offlineDemo`、`history`、`settings` 的所有 Emoji 前缀，统一呈现纯净文字；
  2. [`TonightSkyCard.kt`](file:///c:/starcam/code/app/src/main/java/com/starcam/astro/ui/home/TonightSkyCard.kt)：
     - 顶栏标题移除 `🌌 `，仅保留 `今日天象`；
     - 顶部月相速览按用户决策移除动态符号，仅保留 `上弦月 · 52%` 文本样式；
     - 观星指引建议移除 `✨`/`🔭`/`🌕` 建议前缀图标；
     - 展开月相详情移除 `🌙 `；
     - 展开行星列表逐行移除无意义且雷同的 `🪐 `，直接展示行星名称。

### 2. 设置界面整行点击切换（解决小圆圈命中难问题）
- **问题**：原设置页的单选框（`RadioButton`）与开关（`Switch`）将点击事件仅绑定在控件本身上，整行其余大面积区域不可点，用户必须极度精准瞄准 20dp 的小圆圈才能切换，极易点偏。
- **改动**：在 [`SettingsScreen.kt`](file:///c:/starcam/code/app/src/main/java/com/starcam/astro/ui/settings/SettingsScreen.kt) 中：
  1. 语言选择（`AppLanguage`）、外观主题（`AppThemeMode`）、识别引擎（`EngineMode`）所有选项行引入 `Modifier.selectable(..., role = Role.RadioButton)`，`RadioButton(onClick = null)`，点击整行文字、图标及空白区域即可瞬间切换；
  2. 传感器辅助粗定标、双引擎并发竞速、识别日志记录 `Switch` 选项行引入 `Modifier.toggleable(..., role = Role.Switch)`，`Switch(onCheckedChange = null)`，支持整行触控切换。

### 3. 新增纯黑（AMOLED）与纯白（浅色）双主题
- **设计规范**：
  - 在 [`Theme.kt`](file:///c:/starcam/code/app/src/main/java/com/starcam/astro/ui/theme/Theme.kt) 中扩展 `AppThemeMode`：
    - `PURE_BLACK("pure_black", "纯黑（AMOLED极简）", "Pure Black (AMOLED)")`
    - `PURE_WHITE("pure_white", "纯白（浅色模式）", "Pure White (Light)")`
  - **纯黑主题 (`PureBlackColors`)**：
    - 背景绝对黑 `Color(0xFF000000)`（OLED 像素彻底关闭省电）；
    - 容器层次使用精细中性灰阶（`#121212` / `#1E1E1E` / `#282828`）；
    - 字体采用亮白/中灰高对比度（`#EDEDED`），区别于夜视红的暗适应红光，适合日常夜间深色模式。
  - **纯白主题 (`PureWhiteColors`)**：
    - 首套 Material 3 `lightColorScheme` 浅色主题；
    - 背景纯白 `Color(0xFFFFFFFF)`，容器浅灰分层（`#F7F8FC` / `#F1F3F9` / `#EBEFF5`）；
    - 强调色采纳用户选择的**方案 A（星空深蓝 `#005AC1`）**，具备优良的 WCAG AAA 对比度。
  - [`SettingsRepository.kt`](file:///c:/starcam/code/app/src/main/java/com/starcam/astro/data/SettingsRepository.kt) 与运行时单例 [`ThemeState`](file:///c:/starcam/code/app/src/main/java/com/starcam/astro/ui/theme/Theme.kt) 自动联动即时切换生效，无需重启 Activity。
