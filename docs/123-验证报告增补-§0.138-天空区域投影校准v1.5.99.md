# §0.138 天空区域投影校准（v1.5.99 Debug）

v1.5.98 的补救用两块重叠裁图找到同一组核心恒星。用户样本中的 8 颗核心星集中在天空下半部。沿用局部拟合的投影后，远离这些星点的上缘标注明显偏移。独立盲解确认了星点身份与天区，归因对照见 [§0.137 报告](122-验证报告增补-§0.137-前景干扰与天空区域补救v1.5.98.md)。

## 实现

- 两块裁图用于确认同一组星。补救随后合并上方天空的局部背景提星结果，用已知匹配和新找到的星点重新拟合整图投影。
- 拟合尝试整图中心和原裁图的参考方向。两档搜索用互为最近的星表与像素点配对，先匹配亮星，随后扩大星表范围。固定的一部分恒星保留用于检查，校验覆盖天空上缘和足够宽的区域。证据不足时继续其他求解路径。
- 输出保留现有 TAN WCS 数据结构，单张、批量、历史和原尺寸导出沿用同一投影。已经保存的旧版结果需重新识别照片以更新坐标。
- 原有补救时间片和取消检查贯穿重新提星与拟合。

## 原图复测

在本机用实际照片直接运行生产补救代码，匹配 33 颗，补救阶段约 1.5 秒，结果保持 1080×1354。用已有独立离线盲解提供的星点对照，取其 TAN-SIP 投影误差在 3 像素内的 36 颗参考星。

|---|---:|---:|
| 36 个参考星点误差中位数 | 18.60 像素 | 2.07 像素 |
| 36 个参考星点误差 P90 | 68.90 像素 | 3.30 像素 |
| 原图右上星点偏移 | 98.17 像素 | 5.07 像素 |
| 同一右上星点的球面角误差 | 4.38° | 0.18° |

当前补救使用 TAN，广角镜头畸变仍会留下少量残差。同一右上星点在独立 TAN-SIP 结果中偏 0.83 像素。原图及独立星点坐标留在本机。

```powershell
.\gradlew.bat :app:assembleDebugAndroidTest --offline --console=plain
```

