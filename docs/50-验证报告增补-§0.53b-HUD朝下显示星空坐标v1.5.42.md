# 验证报告增补：§0.53b HUD 朝下显示星空坐标 v1.5.42

## 一、问题（真机反馈）
v1.5.41 实现 AR 全天星空（手机朝下也显示星空）后，相机页顶部 HUD 芯片
在仰角 ≤ 0 时仍显示"🧭 手机未朝向星空（仰角 -xx°）"——与"朝下也在
显示星空"的实际行为矛盾，误导用户。

## 二、修复（最小改动）
- 删除 HUD 的 `!isSky` 分支（CameraScreen），统一显示完整的
  `方位/仰角/预估 RA/Dec`（v1.5.41 起 `buildPointing` 对任意仰角都计算
  RA/Dec，朝下时该分支可达）；
- 保留红/蓝底色区分：朝下仍用红色系底色 + 红字，仅作"地平线以下"的
  视觉提示，不再出现文字性否定；
- 电子水平仪保持 alt>0 门控不变（朝下无取景意义，不属本次问题）。

## 三、验证
- 纯 UI 文案改动，无纯逻辑变更；
- `testDebugUnitTest` 全量回归通过；`assembleDebug` 成功：
  `StarCam-v1.5.42-HUD朝下显示星空坐标-debug.apk`（仅 debug）。
- 真机复测：手机从朝天转到朝地，HUD 全程显示 方位/仰角/RA/Dec
  （朝下时红底色），不再出现"未朝向星空"。
