## 0.1 这是什么项目

Android 天文 App「星空识星」（包名 `com.starcam.astro`，用户亦称「爱观天」）：
**拍一张夜空照片 → 本地离线求解天区（RA/Dec、视场、旋转、parity）→ 在照片上叠加星座连线与星名**。

识别引擎为三层（见 01）：官方 astrometry.net 0.97（NDK 交叉编译 .so，主引擎）→ 自研 919 亮星表三角形匹配（宽场补充）→ 在线 nova.astrometry.net 兜底（可选）。

基础设施特点（**必须遵守**）：

- **本机（Windows）只允许文件读写，禁止编译/跑测试**。机器性能不足。
- **所有 gradle 构建 / JVM 测试 / 交叉编译 / 官方引擎验证都在远端 SSH 服务器 `aa`（<build-server-ip>）上执行**。
- 远端环境已固化（`/etc/environment` 自动加载 PATH 与 PYTHONPATH），新会话零配置即可工作。

## 0.6 别踩的坑（详见 05）

- solve-field 的 `-d` 是 `--depth`（亮星数），**不是** downsample（那是 `--downsample`）。
- astrometry cfg 的 `add_path` 必须指向 `/tmp/wide-test/indexes`（修过，勿改回）。
- 官方 FITS 转 PNM 的 `an-fitstopnm` 有随机 Bus error（对截断文件必崩）。
- GitHub raw 下载 >1MB 文件会静默截断；改用 `api.github.com` + `Accept: application/vnd.github.raw`。
- gradle 单测对 `PHOTO_DIR` 环境变量变化判定 UP-TO-DATE → 强制 `--rerun-tasks`。
- 测试 stdout 被 Gradle 吞 → 读 `app/build/test-results/testDebugUnitTest/TEST-*.xml` 的 `<system-out>`。
