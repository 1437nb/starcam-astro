本轮按「真机测试与兼容性记录」准备验收时，没有检测到实体手机。开发者随后要求在电脑上搭建安卓环境，因此本报告记录 **Android 模拟器实测**。实体手机验收仍待执行。

- Android SDK：`C:\dev\android-sdk`；Android Emulator **37.2.13.0 / build 16740729**。
- `emulator -accel-check`：`WHPX(10.0.26200) is installed and usable`。没有修改 Windows 功能、BIOS 或重启电脑。
- AVD：`C:\dev\android-avd`，Pixel 5 配置，Google APIs x86_64 镜像；每台分配 2 GiB RAM、4 核、software GPU、模拟相机。测试时无界面运行，日常可启动窗口。

## 测试工具调整记录

初版将界面访问混在自定义 Instrumentation 中：API 34 出现 Compose 节点按文本查询未命中；调整为节点遍历后，API 28 又出现 `Error while connecting UiAutomation`，一次命令等待超时。这些是验收工具兼容性问题，未据此修改业务逻辑。

最终将 Android Bitmap / Canvas / 存储 / 批量逻辑测试与主机 ADB UI 驱动分开，先结束 Instrumentation，再由 `uiautomator dump` 读取界面。两个系统重新执行上述 19+9 项全部通过。早期失败记录仍保留在本机 build 目录，不把中间失败删掉或改为成功。

本次 Debug / androidTest APK 构建通过，最终 lint 报告为 **0 Error / Fatal、9 Warning、9 Information**。本轮没有重新运行纯 JVM 336 项；其最近通过记录见 docs/116，不能将它们计入本轮 56 项。

## 启动与复现

本机已安装好镜像和 AVD。在 PowerShell 7 中：

```powershell
cd C:\starcam
.\tools\start_android_emulator.ps1 -Api 34
# 或 Android 9（建议顺序运行，减少主机内存占用）
.\tools\start_android_emulator.ps1 -Api 28
```

默认打开可操作窗口；自动化时加 `-Headless`。API 34 使用 5554 端口，API 28 使用 5556。脚本遇到已运行的 AVD 会直接提示，不重建或清空数据；如需把无界面环境改成窗口，先用 `adb -s emulator-5554 emu kill` 停止该 AVD，再运行启动脚本。

准备测试包时将构建命令分开、串行执行：

```powershell
$env:JAVA_HOME='C:\dev\jdk-17'
cd C:\starcam\code
.\gradlew.bat :app:assembleDebug --offline --console=plain
.\gradlew.bat :app:assembleDebugAndroidTest --offline --console=plain
cd C:\starcam
python tools/android_acceptance.py --serial emulator-5554 --install --ui
# API 28 使用 --serial emulator-5556
```

测试会创建合成素材、公开照片副本和导出图片，不卸载或清空应用。`--install` 使用覆盖安装；Debug 签名不能覆盖官方签名包，不应因此卸载实体手机上的正式版。测试实体手机需明确指定 `--allow-physical`，并先核实安装包签名及测试状态。工具不是任意语言 / 任意历史页面的通用自动化驱动。

验收 Activity 仅位于 `src/debug`，不接受外部文件路径、URL 或命令；测试 runner 位于 `src/androidTest`，没有新增线上服务依赖。`tools/enable_emulator_hypervisor.ps1` 仅作管理员手动启用 WHPX 的备用入口，本机未执行、当前也不需要；它不自动重启。

环境配置参考 Android 官方的 [加速说明](https://developer.android.com/studio/run/emulator-acceleration) 和 [AVD 管理工具说明](https://developer.android.com/tools/avdmanager)。SDK / AVD 在工程外，不入库；本次下载使用的临时网络代理在完成后关闭。
