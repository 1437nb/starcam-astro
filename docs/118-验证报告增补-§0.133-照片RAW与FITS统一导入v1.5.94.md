# §0.133 照片 / RAW / FITS 统一导入（v1.5.94）

日期：2026-11-03。versionCode 114；updateDesc `unified-photo-import`。

## 用户操作

首页点击「导入照片」，直接进入系统文件选择器。普通图片、相机 RAW、FITS 可在同一次选择中混合导入，最多 9 个文件。单选进入单张识别，多选进入现有批量识别页；完成后逐张查看、手动选择图层与导出，返回保留当前批次。

用户不必预先选择 RAW / FITS 专用入口。按钮下明确列出 JPG / PNG / RAW / FITS；「从相册选择 / 更多方式」保留原图相册和系统相册兼容模式，便于访问相册或处理厂商选择器限制。

## 实现与边界

- 主入口使用 `OpenMultipleDocuments`，接受 `*/*`，避免 RAW / FITS 被文件提供方标为通用二进制 MIME 后选不到。系统文件选择器因此也可能显示不支持的文件；看到文件不代表该格式能识别。
- `PhotoImportViewModel` 统一保留显示文件名及扩展名，不再把兼容相册的所有输入都命名为 `.jpg`，避免 DNG 等文件走错解码器。原有后台复制进度、取消及导入失败提示继续使用。
- 超过 9 个文件时整批拒绝，提示重新选择；不静默截断或启动部分导入。
- 格式按保留下来的扩展名交给既有 ImageUtils 管线分派，不是新增通用魔数探测。文件提供方缺少可靠文件名 / MIME 或文件被错误改名时，仍可能无法解码。
- 识别引擎、WCS 与结果页没有因本轮而更换。RAW 继续使用内嵌 JPEG 预览；FITS 继续使用现有拉伸和 HDU 支持，不新增传感器 RAW 解码或压缩 FITS 支持。
- 「统一导入」不会让普通系统照片选择器展示它不支持的 FITS 文件；要混选这些格式应使用首页主入口的系统文件选择器。
