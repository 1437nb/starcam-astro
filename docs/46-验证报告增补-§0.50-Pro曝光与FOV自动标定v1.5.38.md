# 验证报告增补：§0.50 Pro 手动曝光 + 电子水平仪 + FOV 自动标定 v1.5.38

## 一、概述
补齐「拍摄 + AR」两大短板，让手机星空摄影从"自动模式碰运气"升级为
"专业参数可控"：

1. **Pro 手动曝光**：ISO 与快门时长滑块，Camera2 运行时注入（AE off），
   无需重绑 use case；
2. **电子水平仪**：相机滚转角气泡指示，拍地景+星空接片不再歪斜；
3. **AR FOV 自动标定**：从 Camera2 特征直接计算真实视场角，AR 星图开箱即对。

## 二、实现要点

### 1. Pro 手动曝光（`ui/camera/CameraScreen.kt`）
- bind 后经 `Camera2CameraInfo.from(cameraInfo)` 查询设备能力：
  `SENSOR_INFO_SENSITIVITY_RANGE`（ISO 区间）、`SENSOR_INFO_EXPOSURE_TIME_RANGE`
  （快门区间）、`LENS_INFO_AVAILABLE_FOCAL_LENGTHS` + `SENSOR_INFO_PHYSICAL_SIZE`
  （FOV 计算）。任一缺失 → Pro 区不显示（回退 EV）。
- 运行时注入：`Camera2CameraControl.from(cameraControl).setCaptureRequestOptions()`：
  - `CONTROL_AE_MODE = OFF` + `SENSOR_SENSITIVITY` + `SENSOR_EXPOSURE_TIME`（纳秒）；
  - Pro 关闭 → `clearCaptureRequestOptions()` 恢复自动 AE。
- 滑块：ISO 按设备区间夹紧（步进 100）；快门 9 档
  [1/30, 1/8, 1/2, 1, 2, 4, 8, 15, 30] 秒；>1s 显示长曝光提示
  （预览变慢并持续积光，需固定手机）。
- Pro 开启时隐藏 EV/夜景滑块（AE 已关，EV 无意义）。
- 会话级设置（与 EV/闪光灯一致，不持久化）。

### 2. 电子水平仪（`astro/CameraMath.kt` + HUD 旁气泡）
- `rollDeg = atan2(dot(worldUp, right), dot(worldUp, up))`（worldUp=(0,0,1)，
  东北天系下取铅垂方向在相机基上的投影）；
- HUD 下方 58dp 圆形气泡：旋转的地平线 + 度数文本，|roll| < 1° 变绿；
- 复用现有 `pointingState.right/up`，零新增传感器。

### 3. FOV 自动标定（Camera2 → AR 投影）
- `fov = 2·atan(sensorSize/(2·focal))`，按 `SENSOR_ORIENTATION % 180` 与
  竖/横屏选择对应维度（常见后置 90°：竖屏水平视场对应传感器高度维）；
- 成功 → 自动写入 `arFovDeg` 并显示「🎯 视场 XX°（自动标定）」（绿色）；
  手动拖动滑块即转为手动模式；失败（特征缺失/超界）回退手动。

### 4. 纯函数层 `astro/CameraMath.kt`（可单测）
`rollDeg` / `horizontalFovDeg` / `diagonalFovDeg` / `shutterStopsSec` /
`shutterLabel` / `secToNanos` / `clampIso` / `clampExposureNanos`。

## 三、验证
- 新增 `CameraMathTest` 6 项：滚转角零位与旋转跟踪（±10°/30°/−45°）、
  全画幅 50mm 水平 FOV ≈39.6° 与手机 4.3mm/6.4mm ≈77° 数值校验、
  快门档位与纳秒换算、ISO/曝光区间夹紧、对角 FOV 46.8°。
- `testDebugUnitTest` 全量回归通过；`assembleDebug` 成功：
  `StarCam-v1.5.38-Pro曝光与FOV自动标定-debug.apk`（仅 debug）。

## 四、已知边界
- 长曝光下预览帧率随快门变长下降（Camera2 手动曝光固有行为，同时具备
  "积光取景"效果）；
- 部分厂商限制第三方 App 的 ISO 上限/曝光上限（已按设备区间夹紧）；
- FOV 自动标定在个别不报告焦距/传感器尺寸的设备上不可用（回退滑块）。
