# 验证报告增补 §0.22 — 批量识别导出 v1.2.0（2026-08-29）

> 可直接粘贴进 `StarRecognizer\docs\验证报告.md`。新功能版本（minor 升版）。

## 功能

主页「从相册选择星空照片（可多选）」→ 系统相册多选（上限 9 张）→
**批量识别页**逐张自动处理：识别（三层引擎完整链路）→ 叠加渲染 →
自动保存到本地相册 `Pictures/StarCam/StarCam_<时间戳>_<序号>.jpg` →
逐条写入「识别历史」→ 页面实时列表（排队/识别中/✓已导出/✗失败+原因）
与汇总（成功 N/共 M）。

## 实现要点

- **OverlayRenderer**（新增公共渲染器）：识别结果 → 叠加星座位图，
  与「保存到相册」按钮同一渲染样式（v1.0.2 细线半透明规范），含
  scaleWcs 尺寸换算（公式与 rescale 修正式一致：(p−0.5)×k+0.5）。
- **串行处理**：native 求解引擎非线程安全，批量严格串行；
  状态更新回主线程（Compose 状态安全）。
- **多选**：`PickMultipleVisualMedia(maxItems=9)`；选 1 张仍走原单张
  结果页（行为不变），>1 张进批量页。
- 失败项标注原因（无法读取/未能识别/渲染失败/保存失败），不中断批次。

## 验证

- 全量单测 47/47 全绿。
- 构建备注：构建期间 zcode-node-repl-mcp 进程会被客户端自动重启
  （~340MB），需在构建前按 pid 停止；该进程的自动重启行为导致本轮
  多次 OOM 假象（真实编译错误在内存宽裕后暴露并修复：EngineResult 解包）。
