## 一、整改清单与根因闭环

| 编号 | 缺点描述 | 严重度 | 修复方案与代码变更 | 验证断言 / 测试覆盖 |
|---|---|---|---|---|
| **P1-1** | 实时认星叠加忽略 PreviewView 的 FIT_CENTER 几何，直接满屏拉伸 | **P1** | `CameraMath.kt` 增加按实际内容尺寸计算的 `computeFitCenterRect(containerW, containerH, contentW, contentH)`；`CameraScreen.kt` 改用 `Canvas` 将透明标注位图像素级绘制到 `fitRect` 内 | `CameraMathTest.computeFitCenterRectByContentDimensions` |
| **P1-2** | 横竖屏切换后 AR 不重算视场角，沿用旧 FOV | **P1** | `CameraMath.kt` 提炼 `computeCameraHorizontalFovDeg` 纯函数；`CameraScreen.kt` 缓存物理传感器参数，`LaunchedEffect(isPortrait, sensorParams)` 毫秒级重算，无需解绑相机 | `CameraMathTest.computeCameraHorizontalFovDegOrientationSwitch` |
| **P1-3** | 系统返回不取消求解；ViewModel 属于 Activity，Bitmap 跨页面滞留 | **P1** | `ResultScreen.kt` 拦截 `BackHandler` 触发 `viewModel.cancel()`；挂载 `DisposableEffect.onDispose` 触发 `viewModel.onLeaveScreen()` 释放 2200px 位图引用与重置在途任务 | UI 生命周期状态机闭环 |
| **P1-4** | 历史「先复制、后去重」，且 50 条淘汰只删记录不删文件 | **P1** | `HistoryStore.kt` 引入 `computeFileFingerprint` 内容指纹命名 `hist_${sha16}_${len}`，已存文件 0 拷贝复用；`save` 时扫描清理不在列表中的孤儿文件，严格收敛私有存储容量 | `HistoryStoreTest.computeFileFingerprint_stableAndDeterministic` |
| **P1-5** | 非 arm64 机型可装包但窄场无任何可用引擎 | **P1** | `StarSolver.planSteps` 增加 `nativeAvailable` 感知参数，原生不可用时剔除 `ASTROMETRY_NATIVE` 并自动回退 `LOCAL_MATCHER`（若有 Key 仍在线兜底）；`NativeSolveStep` 增加跳过防御 | `StarSolverTest.planSteps_whenNativeUnavailable_skipsNativeAndFallsBackLocal` |
| **P2-1** | 索引文件「长度 > 0 即视为完好」，截断后永久失效 | **P2** | 提炼纯 JVM `FitsIndexValidator.isValidFitsIndex`，严格检验文件长度 ≥2880 且为 2880 整数倍、Header 开头为 `SIMPLE  =`；解压先走 `.tmp` 临时文件原子替换，损坏自愈 | `StellarSolverIndexVerifyTest`（6 项测试，含 8 个内置 FITS 校验） |
| **P2-2** | 默认 30s 求解预算不是全链路硬超时，在线可拖到 4 分钟 | **P2** | `PlateSolveClient.solve` 注入 `timeoutMs` 并联动轮询 deadline；`StarSolver.solve` 与 `OnlineNovaStep` 全链路施加 `withTimeoutOrNull` / `withTimeout` 协程级硬超时 | `PlateSolveClient` 超时联动 |
| **P2-3** | 快速切换标注图层会丢渲染请求，画面与勾选不一致 | **P2** | `ZoomableImageViewer.kt` 将 `renderingNew` 改造为 Conflated / Last-Write-Wins 循环状态机，保证最终渲染位图 100% 对应最后一次勾选的图层 | 图层切换状态同步 |
| **P2-4** | 原生引擎不可复现构建，.so 与源码无绑定校验 | **P2** | `build_so.bat` 编译时计算 `astro_bridge.c` 的 LF 归一化 SHA-256 并生成 `.src_sha256` 清单；`release.py` 在 preflight 前置检查中严格校验源码 SHA 与 `.so` 绑定一致性 | `release.py` 自动化前置检查通过 |
| **P2-5** | 核心几何与防线缺少自动化单测 | **P2** | 新增 `StellarSolverIndexVerifyTest`（6项）、`PlateSolveClientTest`（2项）、扩充 `CameraMathTest`（2项）、`HistoryStoreTest`（1项）、`StarSolverTest`（1项） | 37 类 / 288 项单测全绿 |
| **P3-1** | 深域索引首次构建约 9.3s，且构建段不响应取消 | P3 | `LocalStarMatcher.buildIndex` 内插 `token?.check()` 分段取消检查；捕获 OOM 后设置 60s 冷却期，避免每次求解反复卡顿 | `LocalStarMatcher.index` 冷却与取消保护 |
| **P3-2** | 在线客户端「同图去重」是实例级，跨调用失效 | P3 | `PlateSolveClient` 将 `globalUploadLock` 与 `globalInFlightKeys` 提升至 `companion object`，按文件指纹全局跨实例严格去重互斥 | `PlateSolveClientTest.computeFileKey_stableAndIncludesSizeAndHash` |
| **P3-3** | CI 测试汇总步骤缺报告时仍 `sys.exit(0)` | P3 | `.github/workflows/ci.yml` 缺失 `TEST-*.xml` 报告时改为 `sys.exit(1)` 显式使 CI 失败 | CI 配置加固 |
| **P3-4** | 实时叠加每帧整幅 copy，旧位图仅靠 GC | P3 | `renderLiveOverlay` 改为直接创建透明底位图绘制星座线与标注，0 帧拷贝，高清透出底层实时画面；旧叠加位图在替换与退出时显式 `recycle()` | `CameraScreen.renderLiveOverlay` 零帧拷贝 |
