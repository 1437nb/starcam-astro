# 验证报告增补 §0.13 — 50 张带真值定标图集的识别有效性测试（2026-08-28）

> 可直接粘贴进 `StarRecognizer\docs\验证报告.md`。

## 目标与方法

从公开数据源构建「图内每颗星赤经/赤纬已知」的真实星空图集，用 APP 的两级识别引擎
分别求解，对比真值量化识别有效性。

- 数据源：NASA SkyView（DSS2 Red 数字化巡天底片，8-bit JPEG 快视图，
  WCS 由查询参数解析构造：TAN 投影、CRVAL=视场中心、CDELT=FOV/pixels，
  已与 SkyView FITS 头逐字段核对）。
- 图集：**49 张** 6°~15° 视场（20 个著名星座中心 + 29 个随机天区，
  dec ∈ [-25°, 65°]），1200~2250 px，24~36″/px（手机照片同量级像素密度）。
- 真值：每张的 WCS → 每颗星表亮星 (919, 星表文件投影) 与视场中心的精确天球坐标。
- 引擎 A（官方 0.97，APP 主引擎）：solve-field 带视场先验
  （`--scale-low/--scale-high = 真值 FOV × [0.75, 1.35]`，等效 APP 的 EXIF 焦距→FOV
  先验路径；`--depth 400 --downsample 2 --cpulimit 90`）。
- 引擎 B（自研 LocalStarMatcher，纯 JVM 复现 APP 路径）：`.gray` 管线
  detectStarsGray(60) → match，逐图输出 解出/失败。

## 结果

| 引擎 | 正确解出 | 假阳性 | 中心误差(中位) | 说明 |
|---|---|---|---|---|
| 官方（带视场先验） | **49/49 (100%)** | 0 | **0.01°** | 6°~15° 全覆盖，index-4117 等命中 |
| 自研（919 亮星表） | 0/49 | 0 | — | 视场内星表亮星中位仅 2 颗（6°场 0~3，15°场 1~17），远低于匹配所需 ≥5 颗 → 全部优雅放弃（UNSOLVED），无误报 |

## 结论

1. **APP 主引擎带 EXIF 视场先验时，对 6°~15° 定标真图 100% 正确识别**，
   中心定位误差 0.01°，即引擎求解数学（含 CD 矩阵、parity）与该数据源 WCS 完全自洽。
   注意：服务器解算限时 90s、输入为无损重构图；手机端限时 30s 等效路径尚未真机复测
   （见 §5.2 清单），且手机端无焦距 EXIF 时的盲解能力仍以 §4.2 的 6/12 为准。
2. **自研宽场引擎的视场下界实测**：≤15° 天区 0 解、0 误报——数据确证 919 亮星表
   只支持宽场（估算 ≥20°~25° 且画面含 ≥5 颗 4 等内星表星），与 APP 设计中
   「自研仅作宽场补充、窄场交给官方引擎」的分工一致。
3. 假阳性防护在真值集上得到直接验证：0/49 失败中无一次"解到错误天区"。
