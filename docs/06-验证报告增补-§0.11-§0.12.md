## §0.11 RealPhotoMatchTest 增加真值断言，纳入常驻防回归（42/42）

**改动**（测试代码，不影响 APK 二进制）：

1. `RealPhotoMatchTest.kt` 从 1 个观察性测试扩为 3 个：
   - `apod4BigDipperGroundTruth`：apod4（北斗 34° 场）必须 SOLVED，且断言
     `|RA−187.2|<3°`、`|Dec−56.7|<3°`、`30°<FOV<40°`（真值来自官方 demo/CREDITS
     与官方引擎交叉验证，见 §0.4）。防"识别能力整体失效"。
   - `knownFalsePositivesRemainUnsolved`：apod3 / apod5 / pleiades 必须保持
     UNSOLVED（三者曾是假阳性，是 §0.4 门限收紧的对照样本）。防假阳性回归。
     注释约定：若未来星表升级使某张能正确解出，应改为真值断言而非删除本测试。
   - `matchRealPhotos`：原观察台保留（无断言，结果读 XML `<system-out>`）。
   - 素材缺失时断言失败（回归保护不静默跳过）。
2. `app/build.gradle.kts` 新增 `testOptions.unitTests.all { maxHeapSize = "384m" }`：
   构建机 1.8G 内存上 gradle 守护进程 + 默认 512m 测试 worker 并存会触发内核
   OOM-killer（本日实测两次），384m 后共存无压力。

**验证**：gradle 官方管线 `:app:testDebugUnitTest` 全量 **42/42 全绿**

apod4 断言实测值 RA 187.244 / Dec 56.697 / FOV 34.1°，真值窗口内；三张假阳性样本 UNSOLVED。

**APK**：本次为纯测试改动，APK 无需重发。`assembleDebug` 全 UP-TO-DATE，
SHA-256 仍为基线 `ecde0d25ed80ae02e7d9b4e2768d42ed33fae8918cc7ffdfac328c5ce853e22b`
（25.9MB，签名 fc7144d2… 可覆盖安装），`/opt/APP/app-debug.apk` 部署副本一致。

**环境固化追加**（服务器 aa，自动生效勿重复配置）：
