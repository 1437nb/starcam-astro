# 验证报告增补：§0.51 星座连线对齐 Stellarium v1.5.39

## 一、背景与问题
用户实测反馈：AR 星图/识别结果中**很多星座连线是错的**（如北冕座连线错乱）。
原 `constellationLines` 为项目早期手写数据，覆盖不全、星对错误。

## 二、解决方案：采用 Stellarium 官方西方星文化连线
- **数据源**：Stellarium v23.4 `skycultures/modern/constellationship.fab`
  （默认西方星文化，即传统 Herschel/IAU 线条），GPLv2+ 与项目许可证一致。
  格式：`<缩写> <线段数> <HIP 端点对…>`，共 **88 星座 / 676 条线段**。
- **端点映射**（`tools/gen_lines_stellarium.py`，幂等可重跑）：
  1. 692 个引用 HIP 中，598 个直接命中星表 919 颗真 HIP 亮星；
  2. 94 个暗星端点（4.5 < mag ≤ 6.5，星表内以 hip=120000+HR 存储）
     经 **VizieR TAP（I/239/hip_main）在线查 J2000 坐标**，再按
     ≤0.02° 容差 + 星等一致性 ≤1.5 匹配到星表 BSC5 增补星；
     结果缓存 `hips_stellarium.csv` 供离线复用；
  3. 无法匹配的仅 2 颗（Mira HIP 10826 等长周期变星不在 mag≤6.5 目录），
     其所在 4 条线段跳过。
- 最终 **672 条线段**（去重反向重复），北冕座冠形完整：
  θ-β-α-γ-δ-ε-ι 七星 6 段闭环（α=贯索四）。

## 三、防回归测试（`StellariumLinesTest`，新增 3 项）
- `totalLineCountIsStellariumScale`：线段总数必须落在 600~720（Stellarium 规模），
  防止数据被误裁/混噪；
- `coronaBorealisCrownShape`：北冕座 7 颗冠星（按 J2000 坐标匹配）必须 6 段链式
  相连、无孤立点——直接锁死用户反馈的星座形状；
- `bigDipperShape`：北斗七星勺形 αβγδεζη 六段链锁死。

## 四、验证
- `testDebugUnitTest` 全量回归通过（86 + 3 项）；`assembleDebug` 成功：
  `StarCam-v1.5.39-星座行线对齐Stellarium-debug.apk`（仅 debug）。
- 真机复测：AR 星图与结果页观察北冕座（贯索四冠形）、北斗、猎户等星座，
  连线应与 Stellarium 桌面版一致。
