# StarCam v1.5.59 —— 新增识别日志（失败原因与现场留存）

## 本版新增

### 识别日志：识别不出时，把原因和现场留下来

以前遇到「照片识别不出来」只能靠**截图**推断原因，往往查不出问题。本版加入完整的
识别日志，失败时自动留下可复现的现场数据。

**怎么用**：

1. 识别失败后，结果页下滑点 **「▸ 查看技术细节」** → **「复制」**，
   把内容发出来即可看到引擎轨迹与内部统计；
2. 更完整的信息：**设置 → 识别日志 → 日志目录**，用文件管理器进入该目录，
   取 `starcam-log.txt` 和最新的 `fail-*` 文件夹。

**日志会记录什么**：

- 每次识别用了几层引擎、每层的结果与耗时；
- 失败**归因**：是提星失败、星点太少、还是星点够但匹配不上；
- 自研引擎的内部统计（投票轮 / 打分轮），能区分「真信号缺失」与「参数把关太严」；
- 失败现场的**原始像素数据**（gzip 压缩，无损）—— 开发者可以据此在本机精确重放
  您的照片，不必再靠猜。

**隐私与空间**：

- 只写在应用自己的文件目录（`Android/data/com.starcam.astro/files/logs`），
  **不上传、不联网**；照片路径只记文件名，不记完整路径；
- 像素现场用 gzip 无损压缩（实测 13.8MB → 2.0MB），最多保留 10 份（约 20MB）；
- 日志文本自动滚动截断（512KB）；
- 设置页可一键**关闭**或**清空**。

## 修复

本版无其他功能变更。上一版（v1.5.58）修复的「广角照片识别失败」仍然有效 ——
如果您的照片仍然识别不出，请用本版的日志功能把技术细节发出来，可以直接定位。
