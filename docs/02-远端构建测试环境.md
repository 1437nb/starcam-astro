## 2.3 日常命令模板（全部在 aa 上执行）

```bash
# 1) 同步代码：本地改完文件后上传
#    本地 → aa:/opt/starcam-build/<同路径>（用 ssh_upload 等同工具逐个上传）

# 2) 跑全部单元测试（约 1.5~2 分钟）
cd /opt/starcam-build && export JAVA_HOME=$(ls -d /usr/lib/jvm/java-17-openjdk-17* | head -1) && \
/opt/gradle-8.12.1/bin/gradle --no-daemon --console=plain :app:testDebugUnitTest

# 3) 跑单个测试类（压缩摘要后常用）
/opt/gradle-8.12.1/bin/gradle --no-daemon --console=plain :app:testDebugUnitTest \
  --tests "com.starcam.astro.LocalMatcherTest"

# 4) 强制重跑（PHOTO_DIR 等环境变量变化不会使 gradle 失效 UP-TO-DATE）
/opt/gradle-8.12.1/bin/gradle --no-daemon --console=plain :app:testDebugUnitTest \
  --tests "com.starcam.astro.RealPhotoMatchTest" --rerun-tasks

# 5) 打 APK（约 1~3 分钟；产物 app/build/outputs/apk/debug/app-debug.apk）
/opt/gradle-8.12.1/bin/gradle --no-daemon --console=plain :app:assembleDebug

# 6) 真实照片 JVM 回归台（观察性，输出被 Gradle 吞 → 读 XML）
PHOTO_DIR=/opt/realphotos /opt/gradle-8.12.1/bin/gradle --no-daemon --console=plain \
  :app:testDebugUnitTest --tests "com.starcam.astro.RealPhotoMatchTest" --rerun-tasks
#    结果在 app/build/test-results/testDebugUnitTest/TEST-com.starcam.astro.RealPhotoMatchTest.xml
#    的 <system-out> 节点（CDATA 内 PHOTO 行）。

# 7) 官方引擎验证（对照实验）——正确参数模板
export PATH=...（已有）; export PYTHONPATH=...（已有）
solve-field --no-plots --overwrite --cpulimit 150 --scale-units degwidth \
  --scale-low 10 --scale-high 60 --depth 400 -D solve-xxx photo.jpg
#    注意：--depth 400 = 用前 400 颗亮星建 quad（0.97 默认只取极少星导致 0 quads！）
#    downsample 参数名是 --downsample N（不是 -d！）
```

## 2.4 内存与性能注意

- 2 核/1.8G：gradle 用 `--no-daemon`（守护进程反复失败），构建 1~3 分钟。
- solve-field 对 800px 级 APOD 小图：150s 限时内解不出（卡 4119 宽档）→ **该限制只代表服务器，不代表手机**（手机 8 核 + 同索引已 6/12 验证）。
- an-fitstopnm（FITS→PNM）随机 Bus error：对**截断的 FITS 文件必然崩溃**；下载大文件务必校验大小/可解析性。

## 2.5 网络下载须知（远端 curl）

- Wikimedia Commons：**从本服务器不可达**（超时）→ 不要试。
- GitHub raw：小文件可用；**>1MB 会静默截断**（randomsky.fits 1.4MB vs 应有 2.6MB 就是被截断）。
  - 可靠替代：`curl -sL -H "Accept: application/vnd.github.raw" -o out "https://api.github.com/repos/<owner>/<repo>/contents/<path>?ref=<branch>"`（匿名限流 ~60/h）。
- nova.astrometry.net / apod.nasa.gov：可达。
- jsdelivr CDN（cdn.jsdelivr.net/gh/...）：不保证可用，失败勿重试。

## 2.6 Python 工具（远端 python3，有 astropy + Pillow）

- astropy 读 FITS / 校验下载完整性（`fits.getheader`，报 truncated 即坏）。
- Pillow 批量转 gray 素材（真实照片测试用）：
  `struct.pack("<ii", w, h) + struct.pack("<%df" % (w*h), *pixels)` → `*.gray`。
