## 一、问题背景与改进细节

在首页「今日天象」中，行星胶囊标签此前格式化为 `${planet.name} ${magnitude}m`（例如 `金星 -4.2m`）。用户反馈英文简写 `m`（即 magnitude 缩写）在中文语境下对普通观星爱好者不够直观，且易与米（metre）混淆；而在中文天文学中，视星等的标准习惯表达为“等”（如 `-4.2等`），在英文模式下则通用 `m`。

经全面梳理与优化，完成全 App 视星等表达的规范统一：

1. **首页今日天象行星胶囊（`TonightSkyCard.kt`）**：
   - **优化前**：中文与英文均硬编码拼接 `"m"` 后缀，例如 `金星 -4.2m`。
   - **优化后**：判断当前语言 `isEn`：
     - 中文：`${planet.nameZh} ${String.format(Locale.ROOT, "%+.1f", planet.magnitude)}等`（如 `金星 -4.2等`）；
     - 英文：`${planet.nameEn} ${String.format(Locale.ROOT, "%+.1f", planet.magnitude)}m`（如 `Venus -4.2m`）。

2. **全天体科普卡片统一（`ResultScreen.kt`）**：
   - 排查发现求解结果页天体详情卡片（`ObjectInfoCard`）此前在深空天体、恒星与太阳系天体处硬编码拼接了西方常见的 `"m${mag}"` 前缀（例如中文下出现 `视星等: m2.1`、`视星等: m-4.2`）。
   - **优化后**：全面统一为双语分流：
     - 中文：`视星等: 2.1等` / `视星等: -4.2等`；
     - 英文：`Magnitude: 2.1m` / `Magnitude: -4.2m`。
