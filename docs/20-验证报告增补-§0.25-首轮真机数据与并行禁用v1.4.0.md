## 根因判定：simplexy 在 arm64 真机提星失败

`nstars=0` = .so 的 simplexy_run 返回错误（star-extraction-failed 路径）——
**不是**预算不足（秒败）、**不是**提星少（是 0）。同批图服务器 simplexy 正常、
同 .so 的 SEP 提星路径正常（自研 5 解均用 SEP）。

**头号嫌疑：dsmooth 多线程并行（§3.6 自研改动）在 arm64 的数据竞争**
——该并行代码服务器 x86 验证过，**arm64 真机从未验证**。
