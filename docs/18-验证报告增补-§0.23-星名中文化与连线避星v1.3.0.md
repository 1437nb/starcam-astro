# 验证报告增补 §0.23 — 星名全中文化 + 连线避星 v1.3.0（2026-08-29）

> 可直接粘贴进 `StarRecognizer\docs\验证报告.md`。用户提出两项渲染改动。

## 一、星星名字全部中文（官方中文名优先，拜耳命名法兜底）

- **中文名数据**（新增 `astro/StarNames.kt`）：源 Stellarium 中国星官数据
  `star_names.zh_CN.fab`（3,052 个 HIP 条目，与维基百科传统星名条目同源；
  zh.wikipedia 服务器不可达故用此源），覆盖星表 919 颗中的 **852 颗**。
  同星多名取首个（如 HIP 62572 天枢/纽星 → "天枢"）。
- **拜耳命名法兜底**：源 astrometry.net `catalogs/brightstars-data.c`
  （1,499 行含希腊字母标号，\uXXXX 转义解码后按坐标匹配 HIP，阈值 0.02°），
  匹配 **754 颗**（如 "α CMa"）。注意：其 RA/Dec 与 HIP 有既知错位个例
  （星宿一/Alphard 混淆，§0.19 遗留），按坐标匹配不受名字错标影响。
- **显示规则**（`StarNames.displayName`）：数据集中文名 → 星表既有中文名
  （含中文字符判定）→ 拜耳命名法 → 原西名兜底；919 颗合计覆盖 **884（96%）**。
- 显示条件不变（mag ≤ 3.2 才标注，避免画面拥挤）。
- 遗留：35 颗既无中文名也无拜耳（多为双星辅星等），显示无名。

## 二、星座连线避星（"线和线之间不要连起来"的正确实现）

用户 2026-08-29 澄清：之前的需求"线与线之间的星留空"指**线段不应穿过
星星**——v1.0.2 只移除了星点圆圈，线段仍画到星心，未达意。

- **修复**（`OverlayRenderer.shrink` + 两处渲染接入）：线段两端按端点星等
  收缩 `gap = (4.8 − mag).coerceIn(0.8, 5.0) × 6`（bitmap 像素，亮星空隙更大），
  线在星缘处断开——**星星位置完全留空，露出照片原星**；线段过短（<gap 和
  +2px）则不画。预览（Compose Canvas）与保存/批量导出（OverlayRenderer）
  同款算法，行为一致。
