# 验证报告增补：§0.56b AR 找星导航重做（零分配版）v1.5.46

## 一、背景
v1.5.45 已回滚 v1.5.43（找星导航/点击详情）；本版按"零触 project() 主路径 +
每帧零新建对象"原则重做两项功能。

## 二、与 v1.5.43 的关键差异（消除疑似抖动源）
1. **不再重构 `project()`**：v1.5.43 把投影帧参数抽成 `Frame`/`buildFrame`，
   每帧新建 Frame 对象；本版 `project()` 恢复 v1.5.42 内联形态（零新增分配），
   星图渲染路径与 v1.5.42 完全一致。
2. **`projectPoint` 独立且零分配**：目标方向投影改为独立函数（内联同一套
   针孔/校准数学），scratch 数组（A/C）object 级复用、结果写入调用方数组，
   每帧零新建对象；仅在 `arTarget != null` 时执行。
3. **导航画笔一次性创建**：ring/text/arrow 三个 Paint 在 `remember` 中按
   density 建好，Canvas 逐帧只改 strokeWidth/textSize 并复用——不再每帧
   新建 5 个 Paint。
4. 点击命中 / 科普卡片 / 目标选择弹窗行为与 v1.5.43 一致（tap 时触发，
   不影响每帧路径）；🎯 按钮保留 emoji 显示。

## 三、验证
- 恢复 4 项 projectPoint 几何测试（新签名：返回 Boolean + out[3] 数组）；
- `testDebugUnitTest` 全量回归通过；`assembleDebug` 成功：
  `StarCam-v1.5.46-AR找星导航重做-debug.apk`（仅 debug）。
- 真机复测：① 先装 v1.5.45 确认抖动消失；② 再装本版，功能恢复且
  静止/移动均无抖动；③ 选中目标后观察箭头/光环与星图对齐（含校准平移）。

## 四、遗留说明
若 v1.5.45 复测仍见抖动，问题不在 v1.5.43 功能层，需回查 v1.5.40~42 的
姿态链路（v1.5.44 互补滤波已覆盖硬锚定抖动，可再调 τ 或 predictMs）。
