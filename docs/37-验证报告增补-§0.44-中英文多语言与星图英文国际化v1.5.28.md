## 2. 核心技术设计与架构实现

### 2.1 设置持久化与全局响应式 `LocaleState`
- **`AppLanguage` 枚举**：定义 `FOLLOW_SYSTEM` ("system")、`ZH` ("zh")、`EN` ("en")。
- **`SettingsRepository`**：基于 `SharedPreferences` 增设 `appLanguage` 属性。
- **`LocaleState`（响应式单例）**：
  ```kotlin
  object LocaleState {
      var language by mutableStateOf(AppLanguage.FOLLOW_SYSTEM)
      val isEnglish: Boolean
          get() = when (language) {
              AppLanguage.EN -> true
              AppLanguage.ZH -> false
              AppLanguage.FOLLOW_SYSTEM -> Locale.getDefault().language.lowercase().startsWith("en")
          }
  }
  ```
- **`MainActivity` 动态注入**：在 `setContent` 顶层使用 `CompositionLocalProvider(LocalConfiguration provides ..., LocalContext provides ...)`，用户点击单选框时整棵 Compose 树秒级重组，实现无缝换语。

### 2.2 星座英文全称（`Constellations.kt`）
- 在原有中文映射基础上，新增 88 个星座的 IAU 标准英文/拉丁全称映射 `LATIN`：
  - 例如 `"And" to "Andromeda"`, `"Ori" to "Orion"`, `"UMa" to "Ursa Major"`, `"Cas" to "Cassiopeia"`, `"Cru" to "Crux"` 等全量 88 个。
- 统一双语查询函数：
  ```kotlin
  fun name(abbr: String, isEnglish: Boolean = false): String =
      if (isEnglish) LATIN[abbr] ?: abbr else ZH[abbr] ?: abbr
  ```
- `StarChartOverlay.constellationLabels(stars, isEnglish)` 自动根据传入语言生成标签。

### 2.3 恒星英文专名与 JVM 64KB 限制踩坑（`StarNamesEn.kt`）
- **避坑经验（重大技术细节）**：
  - `StarNames.kt` 原本已有近 3000 行中文星官名和 750 行拜耳标号。在同一个 `object StarNames` 静态初始化方法（`<clinit>`）里塞入英文专名字典，会触发 JVM 字节码硬限制：`MethodTooLargeException: Method too large: com/starcam/astro/astro/StarNames.<clinit> ()V`，导致编译失败。
  - **解决方案**：将英文专名字典独立为 `StarNamesEn.kt`（包含 100+ 颗肉眼和摄影常见主流亮星的标准专名：Sirius、Vega、Betelgeuse、Rigel、Capella、Arcturus、Polaris、Aldebaran、Antares、Spica、Deneb、Regulus 等），在 `StarNames` 中通过属性委托：`val en: Map<Int, String> get() = StarNamesEn.names`，拥有独立的类与初始化方法，完美绕过 64KB 限制，编译速度提升十倍。
- **双语规则**：
  - 英文模式：优先查 `en[hip]` → 查拜耳标号 `bayer[hip]`（如 "α CMa"） → 星表原有非中文名 → 空字符串，绝不输出汉字。
  - 中文模式：保留原有中国传统星官名（"天狼"、"织女一"）。

### 2.4 梅西耶深空天体英文（`MessierCatalog.kt`）
- 在 `MessierObject` 增加 `en: String` 字段。
- 升级 `label(isEnglish: Boolean)` 方法：
  - 英文模式：有专名输出 `"M31 Andromeda Galaxy"`、`"M45 Pleiades"`；无专名仅输出 `"M38"`。
  - 中文模式：有专名输出 `"M31 仙女座星系"`、`"M45 昴星团"`；无专名仅输出 `"M38"`。

### 2.5 渲染链路全线打通
1. **结果页屏幕预览（`ResultScreen.kt`）**：Compose Canvas 绘制直接根据 `LocaleState.isEnglish` 动态绘制英文星座、星名和梅西耶，界面操作按钮支持中英双语（"Annotation / Original", "🔍 Tap image to zoom in"）。
2. **全屏查看器与相册保存（`renderAnnotatedBitmap`）**：接收 `isEnglish` 参数，离屏位图与屏幕预览保持严格一致。
3. **独立位图导出（`OverlayRenderer.kt`）**：`render(bitmap, solve, isEnglish = false)` 暴露语言控制参数。
4. **实时相机取景流（`CameraScreen.kt`）**：取景覆盖层和顶部提示标签根据 `LocaleState.isEnglish` 即时呈现英文标注。
5. **历史记录（`HistoryStore.kt`）**：`nearestConstellation(raDeg, decDeg, isEnglish)` 支持双语返回。
