# 验证报告增补：§0.53 AR 全天星空模式 v1.5.41

## 一、需求
用户要求：手机朝下（指向地面）时 AR 星空也要显示。

## 二、现状与改动
`alt > 0.0` 门控原存在**三处**，本次全部解除：

1. `DeviceOrientationTracker.buildPointing`：RA/Dec 不再限制 alt>0
   （`SkyEphemeris.altAzToRaDec` 本身支持 -90°~+90°，负仰角照常计算）；
2. `CameraScreen` AR `canDraw`：仅需 姿态 + 定位，不再要求朝上；
3. `CameraScreen` 提示块：删除"请朝向星空"分支（仅保留 等待传感器 / 需要定位）。
   （`createPointingHint` 的 alt>0 限制是拍照天区先验的合理要求，保持不变。）

## 三、地平线语义（视觉区分"天上/地下"）
- `StarChartOverlay.Star2D` / `Messier2D` 新增 `belowHorizon: Boolean = false`
  （带默认值，结果页等现有构造零改动）；
- `ArSkyProjector`：`enuToCam` 同时返回世界铅垂分量 u，投影时写入
  `belowHorizon = u < 0`；相机朝下时 z>0.08 视锥门照常工作，自动投影"脚下半球"；
- `LayeredRenderer.draw` 新增 `dimBelowHorizon: Boolean = false`：
  地平线以下的连线（任一端点触发）、星名、梅西耶环/文字按 ~35% 透明度变暗；
  ResultScreen 不传该参数 → 渲染完全不变；
- AR 画布新增**地平线指示线**：地平线是过球心大圆 → 针孔投影为直线，
  由世界铅垂在相机基下的分量 (ru,uu,au)=(right[2],up[2],axis[2]) 解直线方程
  `ru·(u−cx) − uu·(v−cy) + f·au = 0`，画薄荷色虚线 + "— 地平线 —" 标签。

## 四、验证
- `SkyEphemerisTest` 新增：负仰角（alt=-30°, az=180°）RA/Dec 合法且
  dec = alt+lat−90 = −30°、RA = LST（南中天下方 30°，时角 0）；
- `ArSkyProjectorTest` 新增 2 项：相机朝下（axis=(0,0,-1)）投影非空且
  可见星/梅西耶全部 belowHorizon=true；朝上时全部 false；
- `testDebugUnitTest` 全量回归通过；`assembleDebug` 成功：
  `StarCam-v1.5.41-AR全天星空-debug.apk`（仅 debug）。

## 五、已知边界
- 朝下显示的是"脚下半球"的星空：地平线以下元素变暗 + 虚线地平线标记，
  避免与真实天空混淆；
- 地平线指示线基于未校准的姿态（校准偏移只作用于星图平移），定位轻微
  误差属预期，仅作视觉参考；
- HUD 在朝下时同样显示对应 RA/Dec 提示（与全天星空行为一致）。
