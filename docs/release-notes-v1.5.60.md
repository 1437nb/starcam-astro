# StarCam v1.5.60 更新说明

**主题：修复星空照片识别失败与回归（§0.71）**

## 修复内容

### 1. 修复 9-17 拍摄的竖拍照片识别不出来（核心问题）

用户 2026-09-17 拍摄的星空照片（竖拍）此前在 App 中识别失败。
根因是四层缺陷叠加，本次全部修复：

1. **投票阈值量纲错配**：阈值按旧检测器亮度量级标定，而实际用的检测器
   亮度值小得多，导致「主阈值只放进 2 颗星、备用阈值一颗不进」，
   投票轮直接空转。现改为按最亮星比例自适应，两种检测器都能正常工作。
2. **打分轮镜像方向写死**：照片两种镜像奇偶性都存在，写死一个方向会让
   另一类照片全体 0 分。现改为每个候选两个方向都试、取拟合残差小者。
3. **打分轮胜出模型的投影中心不一致**：胜出候选已对齐 24 颗星，但展开
   对应时用了不同的投影中心，导致整个解作废。现统一迭代到画面中心。
4. **赤经跨 0° 接缝**：配对星跨赤经 0° 时求平均会得到完全错误的方向
   （实测偏出 120°+），拟合直接失败。现改用球面向量平均。

### 2. 修复识别结果的随机性（重要）

排查中发现：**同一张照片在不同次运行间会随机出现"能识别/识别不了"翻转**
（演示照片 5057/5087/5092 各出现过；对照样本 apod5 甚至偶尔误报解出）。
根因是索引对同一三角形的重复记录在并列处按哈希遍历序截断，
每次运行顺序可能不同。现规范化索引键并给排序加确定性决胜条件，
**连续 4 次全量回归结果逐位一致**。

### 3. 顺带修复

- 旧照片（9-12 南宁横拍）在开发过程中出现的回归已修复，恢复内点 25。
- 两张原始渲染的南宁照片此前一直识别不出，本次顺带解决（内点 25）。
