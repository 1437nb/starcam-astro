## 功能

用户提出"在电脑上输入命令自动化运行手机测 APP 识别效率"——为此新增
**debug 构建专属的广播触发自动化入口**（`AutoTest`，release 不注册）：

- 主 Activity 启动时注册（`FLAG_DEBUGGABLE` 判定，AGP8 无 BuildConfig 的替代）
- `adb shell am broadcast -a com.starcam.astro.AUTO_TEST --es dir <目录>` 触发
- 对目录内每张 jpg 走**完整三层引擎链路**（与用户手动识别同一代码路径）
- 每张输出 logcat（tag=`STARCAM_TEST`）：
  `<文件> SOLVED|FAILED nstars=.. timeMs=.. [ra=.. dec=.. fov=.. engine=..]`
  结束输出 `ALL-DONE total=N solved=M avgMs=..`
- 失败照片也能拿到提星数：`StellarSolverNative.lastFailNStars`（新增，
  parseJson 失败路径从 native JSON 回读 nstars）

照片放在 APP 专属外部目录（`/sdcard/Android/data/com.starcam.astro/files/`）
——adb 可直接写入且 APP 免存储权限，绕开 Android 10+ 权限问题。

## 真机自动化操作（Windows PowerShell，5 条命令）

```powershell
# 0) 取 APK
scp root@<build-server-ip>:/opt/APP/StarCam-v1.3.1-debug.apk $env:USERPROFILE\Desktop\
# 1) 安装并打开 APP（保持前台不锁屏——识别期间进程需存活）
adb install -r $env:USERPROFILE\Desktop\StarCam-v1.3.1-debug.apk
adb shell am start -n com.starcam.astro/.MainActivity
# 2) 推照片（12 张）到 APP 专属目录（免权限）
adb shell mkdir -p /sdcard/Android/data/com.starcam.astro/files/test12
adb push <本地12张照片目录>\. /sdcard/Android/data/com.starcam.astro/files/test12/
# 3) 一条命令触发全自动化识别（串行走完整引擎链路）
adb shell am broadcast -a com.starcam.astro.AUTO_TEST --es dir /sdcard/Android/data/com.starcam.astro/files/test12
# 4) 收结果（等待完成后；或第 3 步前先开 logcat 实时看）
adb logcat -d -s STARCAM_TEST > $env:USERPROFILE\Desktop\starcam-test.txt
```

把 `starcam-test.txt` 发回会话，即可判读：盲解成功率基线、失败照片
`nstars`（提星质量实锤）、耗时分布 → 决定 v1.4.0 方向（plim 调优 /
盲解预算 / 收工）。
