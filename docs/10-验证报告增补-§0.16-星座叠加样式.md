## 改动（ResultScreen.kt，屏幕叠加 + 保存位图两处同改）

用户需求：让星座叠加更克制、突出照片原星。四处调整：

| 项 | 原值 | 新值 |
|---|---|---|
| 连线宽度 | 2.2 dp（保存图 2.2×density） | **1.2 dp（1.2×density）** |
| 连线透明度 | alpha 0.9 | **alpha 0.55** |
| 星点标记（节点圆点） | 白点（alpha 0.95，亮度定半径） | **移除**——连线端点直接落在照片原星上，不再画点覆盖 |
| 星座名文字透明度 | alpha 1.0（0xFFBBD8FF） | **alpha 0.55（0x8CBBD8FF）** |

星名（亮星中文/西文名）文字保持不变（用户未要求）。
手感目标：细线勾勒 + 原星可见 + 星座名淡淡提示，接近 Stellarium 风格。
