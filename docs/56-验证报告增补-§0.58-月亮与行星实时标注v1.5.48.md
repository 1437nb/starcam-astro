# 验证报告增补：§0.58 月亮与行星实时标注 v1.5.48

## 一、背景与目标
v1.5.47 之前，App 的星空标注只覆盖**恒星**（88 星座连线、3800+ 星名、44 个梅西耶深空天体），
而夜空中最醒目、最常被误认的目标——**月亮与五大行星**——完全没有标注。
用户用广角镜头拍到"一颗特别亮的星"时，无法判断是木星、金星还是土星。

本版新增**太阳系天体标注**：
- 在识别结果图上标注该照片**拍摄瞬间**的月亮、太阳与行星位置；
- 在 AR 实时星图中同步叠加（可随时刻移动）；
- 新增独立图层开关，可随时隐藏；
- 点击标注弹出科普卡片，显示实时观测参数（视星等、距角、被照亮比例、视直径）。

## 二、算法与坐标系（重点）

### 2.1 行星与太阳：JPL 近似开普勒根数
采用 E.M. Standish《Keplerian Elements for Approximate Positions of the Major Planets》
的 J2000 根数表（1800–2050 适用），实现位于 `SolarSystemEphemeris.kt`：

1. 由儒略世纪数 $T$ 线性外推六根数 $a, e, i, L, \varpi, \Omega$；
2. 近日点辐角 $\omega = \varpi - \Omega$，平近点角 $M = L - \varpi$；
3. 牛顿迭代解**开普勒方程** $M = E - e\sin E$（迭代上限 12 次，收敛阈值 $10^{-10}$ 度）；
4. 轨道面内坐标 $x' = a(\cos E - e)$、$y' = a\sqrt{1-e^2}\sin E$，再经三次旋转到 J2000 黄道系；
5. **光行时迭代**：以当前地心距反推光线出发时刻 $\tau = \Delta/c$，重算行星位置（2 次迭代），
   修正量对木星约 30″、海王星约 2′，不可忽略；
6. 黄道 → 赤道（$\\varepsilon_{J2000} = 23.4392911°$）。

### 2.2 月亮：Meeus 第 47 章 ELP-2000/82 截断级数
黄经/距离各 60 项（表 47.A）、黄纬 60 项（表 47.B），外加金星/木星摄动与地球扁率的
附加项；地球轨道偏心率修正因子 $E$（$M$ 项乘 $E$、$2M$ 项乘 $E^2$）完整实现。

### 2.3 坐标系一致性（本节是本版最关键的坑）
**全部输出统一为 J2000 赤道坐标**，与 App 星表（J2000）和 astrometry.net 解出的 WCS（ICRF/J2000）同历元：

- 行星走 JPL 根数表，天然落在 J2000 黄道系，**无需岁差处理**；
- 但 Meeus 月球级数给出的是**当日平分点**黄经，直接当作 J2000 用会产生
  $p = 1.3969713° \cdot T$ 的系统偏差——**2026 年约 0.373°**，即整体偏出约 0.7 个月面直径。
  故显式扣除黄经岁差：$\lambda_{J2000} = \lambda_{date} - p$。
- AR 实时星图使用的平恒星时（GMST）本身也按 J2000 约定参与投影。恒星与行星共用同一套
  约定，其轻微的历元系统差对两者一致，故**相对位置正确**——这正是标注所依赖的。

### 2.4 站心视差修正（必须做，否则月亮整块偏出）
月亮地平视差最大约 57′，地心坐标与用户实际看到的天空位置相差最多约 1.02°。
`applyTopocentricParallax` 按地球扁率（$b/a = 0.99664719$）计算观测地心纬度，
在赤道直角坐标系中做矢量相减后回算 RA/Dec。行星视差通常 <30″，同式一并计算（成本可忽略）。

### 2.5 视星等与视直径
- 行星视星等用 Meeus 第 41 章经验式（含相位角 $i$ 的多项式）；
- 月亮用 Allen (1976) 相位式 $m = -12.73 + 0.026|i| + 4\times10^{-9}i^4$ 加距离模数修正；
- 视直径由赤道半径与地心距实时算出（日月会随距离明显变化，远地点/近地点差约 14%）。

## 三、渲染集成

| 位置 | 做法 |
|---|---|
| `StarChartOverlay.projectSolarSystem` | WCS 投影到画面坐标（与恒星、梅西耶同一条链路） |
| `ArSkyProjector.project(..., solarPositions)` | AR 针孔投影；参数置于末尾以保持既有位置调用不变 |
| `LayeredRenderer` | 新增 `planets` 图层开关；`OverlayScene.solar` 默认空列表（兼容既有构造点） |
| `OverlayRenderer` | 批量导出同步支持（`render(..., solarPositions)`） |
| `ResultScreen` / `ZoomableImageViewer` | 图层开关面板新增「月亮与行星」；保存/预览/查看三处渲染一致 |
| `SkyObjectRef.SolarRef` | 命中测试中**太阳系天体优先级最高**（日月常与深空天体近邻，如月亮掠过毕星团） |

**日月按真实视直径绘制**：渲染器接受 `degPerPx`（板比例），识别页由 `fieldWidthDeg / 位图宽度`
推得、AR 由 `arFovDeg / 视野宽` 推得。有板比例时日月画成真实大小的圆面 + 光晕 + 描边；
无板比例时退化为固定标记环。行星因视直径远小于一像素（木星 31″ 在 30° 视场里仅 0.6px），
一律用标记环绘制。

## 四、精度与独立校验

**校验基准取自 in-the-sky.org 公布的星历**（其后端基于 JPL DE430）：

| 校验项 | 基准值 | 实测 | 偏差 |
|---|---|---|---|
| 木星 2026-09-10 04:00 UTC | RA 09h11m23s / Dec +16°47′34″ | 09h11m53.9s / +16°45′ | ≈0.03°（2′） |
| 土星 2026-09-11 | RA ≈12.7364° / Dec +2.5514° | 00h51m13s / +02°34′ | ≈0.07°（4′） |
| 月亮（月掩木星时刻 2026-09-08 18:44 UTC） | RA 137.83333° / Dec +17.58333° | 见测试断言 | <0.2° |
| 根数表交叉核对 | in-the-sky 给出木星 $\omega=-85.75°$、$\Omega=100.47°$、$M_0=19.67°$ | 由 JPL 表推得 14.72848−…、$M_0=19.66796°$ | 吻合到 0.01° |
| 上弦月 2026-09-18 20:44 UTC | 日月距角 = 90°（定义） | 见测试断言 | <1.5° |
| 新月 2026-09-11 | — | 反推新月 09-11 04:15 UTC | 日期吻合 |

此外用**不依赖外部数据的物理约束**做了兜底校验：行星走完一个公转周期后日心位置必须复位、
日心距必须落在 $a(1\pm e)$ 区间、日月在二分二至的赤纬、内行星距角上限、
月地距离 356,400–406,700 km、月面视直径 29.3′–34.1′、月相与距角的解析关系等。

## 六、已知限制与后续方向
1. **必须有 EXIF 时间 + GPS 才标注**。日月行星位置随时刻剧烈变化（月亮每小时走约 0.55°），
   缺任一项就无法定位，此时一律不标注——**宁可不标也不能标错**。
   后续可考虑：无 GPS 时用当前定位兜底并明确提示用户「位置来源为当前定位，可能不准」。
2. **土星环倾角效应未计入**星等（误差 ≤0.4 等，不影响绘制）。
3. **未含小行星与矮行星**（谷神星、灶神星等），亮度接近肉眼极限，收益低。
4. 精度上限：行星受近似根数表限制约 1–5′，月亮受级数截断限制约 1′；
   对 10°–60° 视场的广角标注（1′ ≈ 画面千分之一）完全够用。
   若将来做长焦深空摄影的精细标注，可换用完整 VSOP87 + ELP2000-82B。
