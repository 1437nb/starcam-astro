# 验证报告增补：§0.47b 图层渲染与科普卡片修复 v1.5.33

## 一、问题（v1.5.32 真机反馈：「天体科普卡片没有生效」）

排查确认 v1.5.32 引入 **两处连带回归**，一并修复：

### 1. 科普卡片几乎点不中（功能失效根因）
- `hitTestObject` 的命中容差误用**图像像素**（28px/36px）而非屏幕像素。
- 结果页显示位图长约 2200px，fit-scale ≈ 0.45 → 屏幕上实际容差仅 **4~5dp**，
  手指几乎不可能点中任何梅西耶圆圈或亮星 → 点击全部落入"放大查看器"分支。
- **修复**：容差改为屏幕坐标系的 28dp（梅西耶）/ 32dp（亮星），由调用方
  `LocalDensity` 换算成屏幕像素传入；命中测试改为"投影坐标 × fit-scale → 屏幕坐标"
  与点击点直接比较（同时减去 letterbox 居中偏移）。

### 2. 预览叠加层字号/线宽坍缩（视觉回归）
- 统一渲染器 `LayeredRenderer.draw` 把**字号、线宽、圆圈半径也乘了 sx 缩放系数**。
- 预览画布宽 ≈ 位图宽的 45% → 文字缩成 ~5px、线宽 0.5px、圆圈 3px，
  结果页预览的星座名/星名/梅西耶标注几乎不可见。
- （导出位图与放大查看器路径 sx=1 不受影响，因此 v1.5.32 保存/查看正常，仅预览异常）
- **修复**：坐标仍按 sx/sy 缩放（图像坐标 → 画布像素），但**字号/线宽/半径/偏移
  一律为画布绝对像素**，不再乘 sx。预览调用改传 `density = 1.sp.toPx()`
  （≈2.75px/sp，含系统字体缩放）；导出位图路径维持 `density = 2.0` 不变。

### 3. 体验优化（顺带）
- 科普卡片从"推挤列表布局"改为**照片底部浮层**（`align(BottomCenter)` +
  fillMaxWidth），点中即现，位置直观；
- 移除 `flags.allEnabled` 总闸（部分图层关闭时其余图层仍正常绘制，由渲染器逐层跳过）；
- 移除按住原图的 Crossfade 动画（避免同图双层淡入淡出的瞬时叠加），改为直接切换。
