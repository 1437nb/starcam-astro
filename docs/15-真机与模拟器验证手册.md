# 真机/模拟器验证手册 — v1.1.0（2026-08-29）

> 目的：在真实 Android 环境（模拟器或手机）跑 v1.1.0，完成服务器无法闭环的
> 三件事：① 12 张实拍盲解成功率；② `nstars` 提星诊断数据；③ 新功能链路
> （识别历史/弱光模式/保存相册）。做完把数据发回服务器即可。

## 1. 方案 A：PC 模拟器（无手机时用，10 分钟）

1. 装 Android Studio（含 adb）→ Device Manager → Create Device：
   - 机型 Pixel 7，系统镜像 **API 34 (Android 14) x86_64**
2. 启动模拟器后安装：
   ```powershell
   adb install -r $env:USERPROFILE\Desktop\starcam-v110.apk
   adb push $env:USERPROFILE\Desktop\photos12\. /sdcard/Pictures/
   ```
3. **注意**：模拟器 x86_64 通过 ARM 转译运行我们的 arm64 引擎，
   **求解速度慢 2~5 倍、盲解成功率会偏低**——结论打折扣用；
   界面/历史/弱光等功能验证完全有效。

## 2. 方案 C：真机（推荐，结果最准）

1. 手机开启「开发者选项 → USB 调试」，连电脑
2. 安装并跑 12 张照片（相册导入 → 逐张识别；建议**不开定位**——正好测盲解）：
   ```powershell
   adb install -r $env:USERPROFILE\Desktop\starcam-v110.apk
   adb push $env:USERPROFILE\Desktop\photos12\. /sdcard/Pictures/photos12/
   ```
3. 记录每张：解出/失败（失败时结果页文案有「第 x/2 段」信息，一并截图）

## 3. 采集日志（核心——nstars 诊断）

跑完 12 张后立即执行：

```powershell
adb logcat -d > $env:USERPROFILE\Desktop\starcam-log.txt
adb shell dumpsys meminfo com.starcam.astro >> $env:USERPROFILE\Desktop\starcam-log.txt
```

把 `starcam-log.txt` + 每张照片的解出/失败清单发回（贴到会话即可）。
分析要点：失败照片的 `nstars`（提星数）——**<60 则坐实提星差距**，
下一轮就启用 plim 调优；≥100 则嫌疑转向其他环节。

## 5. 结果判读（回传后我来做）

| 数据 | 判定 |
|---|---|
| 盲解 ≥9/12 | 手机端与服务器模拟对齐，识别侧收工 |
